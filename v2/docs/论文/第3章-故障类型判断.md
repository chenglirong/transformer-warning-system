# 第3章 基于多规则协同的变压器油中溶解气体故障类型智能判断技术

## 3.1 引言

第2章已给出检测分级、总烃月环比和涨势预警。气体含量达到注意值，或产气速率明显加快时，还须判断可能的故障类型，并给出进一步试验建议。按DL/T 722—2014[6]第10.3条，应先将检测结果与含量注意值、产气速率注意值比较；当认为设备内部存在故障时，再用第10.1条、第10.2条所述方法，并参考该标准附录A、附录B和附录C，对故障类型进行判断；同条还指出，可结合该标准附录D给出的其他试验项目作后续安排。

本章在此基础上研究多规则协同的故障类型智能判断。用双门槛衔接第2章结果：检测分级达到注意值2或告警，或总烃月环比超注意（含涨势预警），即可进入判型。同时采用特征气体法、三比值法与大卫三角形法，经交叉研判按优先级确定主结论，并完成性质核对和可信度标注。试验建议按该标准附录D表D.1整理，细项再按DL/T 1685—2017[8]附录B补充，形成可核对的清单。

## 3.2 相关研究与问题分析

传统规则方法仍是油中溶解气体故障类型判断的常用判据。三比值法用编码查表，做法直观；大卫三角形法按平面分区判断，可补上三比值法部分无对应编码的情形；特征气体法则根据主要气体、次要气体组合，给出过热或放电一类定性判断[13][35]。有综述指出，只用一种方法时，边界样本上可能判错，实际工作中往往要几种方法一起看[13]。尹琦琳在220kV变压器油色谱异常处置中写明：先用含量注意值与产气速率判断法作故障识别，再结合特征气体法、改良三比值法、大卫三角形图示法与比值判断法作故障类型与趋势综合诊断[23]。

结合现有系统实现和实际使用情况，仍存在以下三点不足。

触发判型条件不合理。只凭当日检测分级触发判型，会漏掉涨势预警对应的早期速率异常；若气体含量正常、也无增长趋势时仍频繁做比值判型，结论往往没有意义。DL/T 722—2014要求判型一般出现在注意值或增长趋势之后，自动化实现需要把这一原则落成可计算的门槛。

多方法协同不足。特征气体法、三比值法与大卫三角形法有时会给出不同结论。只用一种方法，在边界样本和混合故障上容易判错[13]。几种方法结论对不上时，还须给出可信度，否则就不知道该信哪一个。

试验建议难落到项目。DL/T 722—2014[6]附录D表D.1与DL/T 1685—2017[8]附录B已列出可安排的试验项目；若输出只写“建议进一步试验”一类笼统说法，不对应到上述项目，判出类型之后仍不清楚该做哪些试验。

针对上述不足，本章提出以下改进：

提出双门槛触发判型条件。以检测分级达到注意值2或告警，或总烃月环比超注意（含涨势预警）作为进入判型的条件；气体含量正常且无增长趋势时不做比值判型。该门槛对应DL/T 722—2014[6]第10.2.4条a）与第10.3条，并与第2章涨势预警衔接。

构建多规则协同的故障类型判断方法。同时采用特征气体法、三比值法与大卫三角形法，按优先级确定主结论，并给出可信度，避免只给出单一方法结果、看不出该信哪一个。

建立对应标准附录的试验建议输出。按DL/T 722—2014[6]附录D表D.1与DL/T 1685—2017[8]附录B列出具体试验项目，不写“建议进一步试验”一类笼统说法。

## 3.3 故障类型判断触发条件与适用边界

双门槛条件见第3.2节。这里只区分两套规则：能不能做故障类型判断，和给不给处置紧急度。本文所称“相对产气速率超注意”即第2.6节涨势预警对应的判据，二者同源；判型门槛与涨势预警门槛在算法上是同一次比较。总烃月环比超注意（含涨势预警）时，即使检测分级还是正常或注意值1，也可以进入判型；但处置紧急度仍只在检测分级达到注意值2或告警时才给出。因此可能出现“已可判型、尚无紧急度”的情况；进入判型也不会改写紧急度结果。

## 3.4 基于特征气体法的故障类型判断方法

特征气体法按DL/T 722—2014[6]第10.1条。按该标准第4章关于油中溶解气体产生的基本原则，不同故障类型的主要特征气体与次要特征气体归纳为该标准表5，可据此推断故障类型。该标准表5整理如表3.1所示。


表3.1　DL/T 722—2014[6]表5　不同故障类型产生的气体

| 故障类型           | 主要特征气体       | 次要特征气体     |
| ------------------ | ------------------ | ---------------- |
| 油过热             | CH₄、C₂H₄          | H₂、C₂H₆         |
| 油和纸过热         | CH₄、C₂H₄、CO      | H₂、C₂H₆、CO₂    |
| 油纸绝缘中局部放电 | H₂、CH₄、CO        | C₂H₄、C₂H₆、C₂H₂ |
| 油中火花放电       | H₂、C₂H₂           |                  |
| 油中电弧           | H₂、C₂H₂、C₂H₄     | CH₄、C₂H₆        |
| 油和纸中电弧       | H₂、C₂H₂、C₂H₄、CO | CH₄、C₂H₆、CO₂   |

该标准表5注1～注5为行业标准给出的定性细则，与表5正文一并使用，要点如下。

注1：过热故障还可按温区进一步细分（细分类别见该标准表7）。
注2：出现一氧化碳、二氧化碳时，可能涉及固体绝缘材料。
注3：局部放电通常少产或不产乙炔。
注4：火花放电时乙炔往往增长较快，但总烃一般不高。
注5：电弧属于高能放电。

乙炔常用来区分过热与放电：高温过热也可能出现少量乙炔，但放电时乙炔通常更突出；氢气升高则不一定是放电，受潮或油中气泡也可能引起。

本文按该标准表5做定性匹配。输入为当日气体浓度。氢气、甲烷、乙烯、乙烷、乙炔中，若测到的不足三种，则判为数据不足，不再匹配。该标准表5只列出各故障对应的主要、次要气体，没有规定浓度要多高才算出现；匹配时，主气中除一氧化碳、二氧化碳外，浓度大于0即参加比较；一氧化碳、二氧化碳是否参加比较由所在行是否为油纸相关故障决定（见下句）。油和纸过热、油纸局部放电、油和纸中电弧等行还含固体绝缘相关气体，另按DL/T 722—2014[6]第10.2.3.1条，要求二氧化碳与一氧化碳比值小于3。乙炔已达该标准表3注意值时，不采用局部放电行（注3）；总烃已达该标准表3注意值时，不采用火花放电行（注4）。该标准表3注意值在此只作排除用，与第2章表2.1落档阈值分开。多行都满足时，先看次气匹配多少，再看主气个数，择优一行。输出故障名称、性质大类（过热或放电）、是否匹配成功，以及注1～注5相关附注。

## 3.5 基于三比值法的故障类型判断方法

三比值法按DL/T 722—2014[6]第10.2.1条。该方法利用故障下油与绝缘材料裂解产气时，组分相对浓度随温度变化的关系：从五种特征气体中选取溶解度和扩散系数相近的气体，组成三对比值并编码，再按编码查表判断故障性质。它是在IEC 60599基础上，结合国内实践经验改良得到的。三对比值为C₂H₂/C₂H₄、CH₄/H₂、C₂H₄/C₂H₆；编码规则与故障类型判断方法分别见该标准表6、表7，本文整理为表3.2和表3.3。编码组合有限，部分故障类型无法直接对应，实践中需与其他方法一起使用[13]。


该标准表6的编码规则整理如表3.2所示。其中CH₄/H₂一列与另两列不同：比值由小到大时，编码依次为1、0、2，并不是随比值增大而单调升高。

表3.2　DL/T 722—2014[6]表6　三比值法编码规则

| 气体比值范围 | C₂H₂/C₂H₄ 编码 | CH₄/H₂ 编码 | C₂H₄/C₂H₆ 编码 |
| ------------ | -------------- | ----------- | -------------- |
| ＜0.1        | 0              | 1           | 0              |
| ≥0.1～＜1    | 1              | 0           | 0              |
| ≥1～＜3      | 1              | 2           | 1              |
| ≥3           | 2              | 2           | 2              |

表3.3　DL/T 722—2014[6]表7　故障类型判断方法

输入为氢气、甲烷、乙烯、乙烷、乙炔五种气体。DL/T 722—2014[6]第10.2.4条c）指出，气体浓度低于10 μL/L时，比值精确度会迅速降低。五种气体都小于10 μL/L时，不再计算比值，判为数据不足。任一比值分母过小无法计算时，判为无对应编码。为与大卫三角形法对照，还将该标准表7故障类型对应到六代码（低温过热为T1，中温过热为T2，高温过热为T3，局部放电为PD，低能放电为D1，电弧放电为D2）；该对应只用于方法间核对，对外展示仍用该标准表7原文故障名称与三元组编码。

## 3.6 基于大卫三角形法的故障类型判断方法

大卫三角形法按DL/T 722—2014[6]附录C。取甲烷、乙烯、乙炔三种气体，按该标准附录C公式（C.1）至（C.3）换算为百分比坐标，再按该标准附录C图C.2在平面三角形中分区判定故障类型。该方法不依赖三比值编码表，对该标准表7未列出的编码组合仍可给出分区结果。

百分比坐标按该标准附录C下列公式计算：

$$
\%\mathrm{C}_2\mathrm{H}_2=\frac{100X}{X+Y+Z}\qquad(\mathrm{C}.1)
$$

$$
\%\mathrm{C}_2\mathrm{H}_4=\frac{100Y}{X+Y+Z}\qquad(\mathrm{C}.2)
$$

$$
\%\mathrm{CH}_4=\frac{100Z}{X+Y+Z}\qquad(\mathrm{C}.3)
$$

式中：
$X$——C₂H₂含量，μL/L；
$Y$——C₂H₄含量，μL/L；
$Z$——CH₄含量，μL/L。

该标准附录C图C.2的分区示意如图3.2所示。各区故障类型与该标准附录C表C.1一致，整理如表3.4所示。

## 3.7 多规则协同判断与可信度标注方法

特征气体法、三比值法与大卫三角形法单独使用时，在边界样本上可能给出不同结论。DL/T 722—2014[6]要求几种方法相互印证。本章在三法各自算完后做交叉研判：按固定优先级只取一个对外故障名称，再核对这些结果在过热与放电性质上是否矛盾，最后按表3.5标注可信度。不做简单投票。需要说明的是，主结论优先级、编码一致性核对与可信度标注都为本文为系统实现制定的协同规则，用于将多种判据汇总为单一输出；行业标准提供的是各单项判据及其应用原则。

（1）三法各自独立计算。特征气体法、三比值法与大卫三角形法互不依赖，分别给出各自结果（见第3.4节至第3.6节）。三比值法与大卫三角形法共用六代码口径，便于对照；特征气体法保留该标准表5原话，不硬改成六代码。

（2）按优先级确定主结论。对外只保留一个故障名称，顺序为：大卫三角形法有效时用其结果；否则用三比值法；再否则用特征气体法；三者都无效则判为无法判定。这样排，是因为大卫三角形法与三比值法共用同一套故障编码，便于互相比对；特征气体法偏定性、边界较粗，用作后备。

（3）核对性质是否一致。把各法结果归到过热、放电、放电兼过热三类。若至少两种方法分别给出纯过热与纯放电，判为性质不一致；若纯过热或纯放电意见一致，或出现放电兼过热，则判为一致。另将三比值六代码与大卫三角形区代码对照：二者相同，或属于相邻区域，视为编码一致；否则视为编码不一致。相邻判定用来避免编码落在交界附近时被当成硬冲突。

（4）标注可信度。主结论与性质核对完成后，按表3.5依次判断，先命中的规则生效，给出高、中、低三档。可信度为低时，结论标为暂定，试验建议用“核实”措辞；否则用“推荐”措辞。

表3.5　交叉研判可信度规则

| 顺序 | 条件 | 可信度 |
| ---- | ---- | ------ |
| 1 | 五烃都有值且都＜10 μL/L（DL/T 722—2014[6]第10.2.4条c） | 低 |
| 2 | 性质大类不一致（放电与过热相互矛盾） | 低 |
| 3 | 三比值与大卫三角形法编码不一致，且性质大类亦未一致 | 低 |
| 4 | 性质大类一致且编码一致 | 高 |
| 5 | 性质大类一致或编码一致（仅其一成立） | 中 |
| 6 | 其余情形（如有效方法偏少） | 中 |

辅助比值按DL/T 722—2014[6]第10.2.3条计算，只写在附注里，不改主结论。本文用两组：CO₂/CO小于3，提示可能涉及固体绝缘；大于7，提示多属正常老化；C₂H₂/H₂大于2，提示有载分接开关油可能渗入本体。同条还有O₂/N₂，本文数据没有这两种气体，故不做。另须分清：第3.4节里CO₂/CO小于3，是特征气体法匹配“油和纸”相关行的条件；这里是主结论定了之后再加的附注，两处不是同一用途。只有性质大类一致时，才附油纸绝缘相关说明。

## 3.8 进一步试验建议输出方法

仅给出故障类型名称，尚不足以安排复查试验。本章按两层给出试验建议：先按故障性质（过热、放电或放电兼过热），从DL/T 722—2014[6]附录D表D.1对应列取出试验项目，放电兼过热取两列并集并去重；再按当日气体情况，对照DL/T 1685—2017[8]附录B补充细项，例如与乙烯、乙炔、总烃、一氧化碳等相关的铁芯、直流电阻、局部放电、有载开关检查等。两层合并去重后形成清单，并写明依据：当前是何种状态、对照哪张表、建议做哪几项。

交叉研判结论为暂定时，清单用“核实”措辞；否则用“推荐”措辞。输出只到试验项目清单，由运维或试验部门安排复查，不给出停电或检修指令。

## 3.9 方法验证与案例分析

### 3.9.1 方案设计与判定标准

本章只核对判型结果：以各案例最后一次取样（末样）对照该附录性质结论，把主结论归到过热、放电或放电兼过热后，是否与DL/T 722—2014[6]附录E对照性质一致；准确率按17组末样计，不以全部62个取样点作分母。含多个取样点的案例，再按各次取样的先后，看故障性质有没有变化。验证时一律进入判型，不测双门槛；双门槛和第2章衔接，完整流程见第4章。试验建议清单在第4章报告和第5章界面中核对，本节不单独统计。

## 3.10 本章小结

本章主要处理三个问题：触发判型条件不够清楚、多方法协同不足，以及试验建议不容易落到具体项目。本文以检测分级达到注意值2或告警、或总烃月环比超注意（含涨势预警）为双门槛进入判型，避免只看检测分级而漏掉早期涨势；并行采用特征气体法、三比值法与大卫三角形法，按优先级确定主结论，并做性质核对和可信度标注，可信度低时标为暂定；试验建议则按DL/T 722—2014[6]附录D与DL/T 1685—2017[8]附录B列出具体项目，并在第4章报告和第5章界面中核对。在该标准附录E共17组真实色谱案例上，性质大类判断准确率为88.2%；未命中的两例都为放电兼过热，说明只看末样时气体特征可能偏向一侧，按多次取样连续判型更容易看出先后变化。本章结果供第4章智能体的监测决策和报告生成使用。
