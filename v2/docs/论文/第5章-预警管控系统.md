# 第5章 变压器油中溶解气体分析预警系统设计与实现

## 5.1 系统总体架构设计

第2至第4章已经分别给出检测分级与涨势预警、多规则故障判型，以及分析智能体工作流。本章把这些方法做成可运行的原型系统，用来演示完整流程并生成报告。七步分析、监测决策和报告由智能体服务完成，其他页面只展示同一套计算结果，避免各入口各算一套。

系统前后端分离，总体结构如图1.1所示，自上而下分为展示、接口、分析智能体、算法引擎和数据存储五层。只有展示层与接口层用HTTP/REST通信，其余在进程内调用。算法引擎按行业标准做判定，智能体层按固定七步编排分析，大语言模型只润色报告与解释文字。数据存储层只存气体浓度时序和设备基本信息，分析结论每次按规则现算。

## 5.2 核心功能模块设计

### 5.2.1 检测分级与告警模块

本模块对应第2章，侧栏有检测分级页和告警列表页。检测分级页按日给出第2章表2.1各项结果，以及总烃月环比、涨势预警和处置紧急度；告警列表按日列出全年四档记录，涨势预警单独一列。页面截图见第5.4.2节、第5.4.3节。

### 5.2.2 故障类型判断模块

本模块对应第3章，侧栏为故障判型页。当检测分级到注意值2或告警，或总烃月环比已超注意（含涨势预警）时触发判型，并行做三法交叉研判并给出主结论与可信度；不到门槛时提示当日不做判型。试验建议的完整清单在智能体分析页给出。页面截图见第5.4.6节。

### 5.2.3 智能体服务模块

本模块对应第4章，主入口是智能体分析页：按七步跑完分析，给出运行日志、监测决策和报告预览，也可下载PDF。分析助手嵌在同一页，与主界面共用同一次七步结果。页面截图见第5.4.7节、第5.4.8节。

## 5.3 数据库与数据流设计

### 5.3.1 核心数据表与字段设计

数据库有两张表。气体浓度时序表按监测日保存七种气体浓度，同一日只保留一条记录，主要字段如表5.1所示；设备基本信息表保存报告要用的设备字段，如型号、电压容量、油重、油种、制造厂和投运信息等，对应第4章分析报告基本信息区，主要字段如表5.2所示。

表5.1　气体浓度时序表（monitoring）主要字段

| 字段 | 含义 |
| ---- | ---- |
| transformer_id, date | 设备编号与监测日（唯一约束） |
| H₂、CH₄、C₂H₄、C₂H₆、C₂H₂、CO、CO₂ | 七种气体浓度（μL/L） |

表5.2　设备基本信息表（transformers，对齐分析报告）主要字段

| 字段 | 含义 |
| ---- | ---- |
| transformer_id | 设备编号 |
| bureau, model, voltage_capacity | 局（厂、所）、型号、电压等级/容量 |
| oil_weight_t, oil_type | 油重（t）、油种 |
| manufacturer, serial_no | 制造厂、出厂序号 |
| manufacture_date, commission_date | 出厂年月、投运日期 |
| cooling, tap_changer, oil_protection | 冷却方式、调压方式、油保护方式 |

### 5.3.2 端到端数据流转设计

先把气体浓度时序和设备基本信息写入数据库。用户选定监测日后，接口层发起分析：算法引擎算出分级、趋势、紧急度、判型和监测决策，智能体层按七步汇总并生成报告，再送到各页面显示。页面自己不算判据。

## 5.5 系统验证与演示分析

### 5.5.1 端到端流程验证

导入合成演示时序和设备基本信息后，任选一天跑智能体分析，七步能跑通，报告也能生成。再用第2.8.4节、第2.8.5节与第3.9.4节的验证案例做核对：分别看检测分级、处置紧急度与故障性质大类，结果与前面章节一致。

### 5.5.2 典型场景演示与结果分析

典型演示走三条路径。一是，在智能体分析页选监测日跑七步，再打开分析助手追问分级条件、涨势预警或试验建议，对照主界面日志。二是，直接在分析助手里请求分析某天，主界面跟着更新；以2024-08-09为例，两个入口给出的分级、紧急度和判型相同。三是，从检测分级页或告警列表页进到智能体分析，并导出PDF。三条路径合起来看，第2至第4章的方法已经落到界面上，各入口结论一致。

## 5.6 本章小结

本章把第2至第4章的方法实现为原型系统。系统前后端分离，按五层划分，设置检测分级与告警、故障判型、智能体三大模块：前两者负责第2、第3章规则计算，智能体负责七步工作流编排。数据存储层保存气体浓度时序和设备基本信息，结论按规则即时计算，并在数据集、检测分级、告警列表、产气趋势、决策列表、故障判型、智能体分析（含助手和报告导出）以及判据知识库等界面中展示。端到端演示和行业标准案例核对表明，系统可正常运行，结果也与第2、第3章规则一致。
