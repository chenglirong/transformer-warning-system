## 2 分级模型

### 2.1 模型结构

分级模型为**三组阈值查表模型**，每组按三档下限判定，取最高档。

```
输入: 7 气浓度(μL/L)
  ↓
┌─────────────────────────────────────────┐
│  ① 绝对浓度查表: C₂H₂ / H₂ / 总烃      │
│  ② 绝对增量查表: C₂H₂ / H₂ / 总烃      │
│  ③ 相对增长速率查表: 总烃               │
│  特判: C₂H₂ 从无到有 → 注意值1           │
└─────────────────────────────────────────┘
  ↓ 取最高档
输出: 综合档位(正常/注意值1/注意值2/告警值)
```

### 2.2 阈值参数（表A.3，220kV 及以下）

判档规则：达到某档**下限**即进入该档；未达注意值1 即为正常。「—」表示该档无定义，不再升档。

**① 绝对浓度**（μL/L）：


| 气体   | 正常   | 注意值1 | 注意值2 | 告警值 |
| ------ | ------ | ------- | ------- | ------ |
| C₂H₂ | <1.0   | ≥1.0   | ≥5.0   | ≥8.0  |
| H₂    | <120.0 | ≥120.0 | ≥150.0 | —     |
| 总烃   | <120.0 | ≥120.0 | ≥150.0 | —     |

**② 绝对增量**（μL/L·周：


| 气体   | 正常  | 注意值1                 | 注意值2 | 告警值 |
| ------ | ----- | ----------------------- | ------- | ------ |
| C₂H₂ | <1.0  | 「从无到有」或增量≥1.0 | ≥2.0   | ≥4.0  |
| H₂    | <15.0 | ≥15.0                  | ≥30.0  | —     |
| 总烃   | <15.0 | ≥15.0                  | ≥30.0  | —     |

**③ 相对增长速率**（仅总烃，%/周；参比总烃 <30 μL/L 时不计算）：


| 气体 | 正常  | 注意值1 | 注意值2 | 告警值 |
| ---- | ----- | ------- | ------- | ------ |
| 总烃 | <30.0 | ≥30.0  | ≥60.0  | —     |

### 2.3 设计约束

- 「—」表示该档无定义（如 H₂/总烃 无告警值档），不再升档
- 总烃参比 <30 μL/L 时不计算相对增长速率
- 在运声明下只走 A.3.3 a)；序列开头不足参比窗 → 增量/增长率报「正常」并注「参比窗不足」；不启用 b)

## 3 紧急度与涨势预警模型

### 3.1 紧急度模型结构

条件分支模型，仅在档位≥注意值2时启动，不改档位。

```
输入: grade(档位) + thc_rel_rate(月环比) + rising(速率超) + indicators
  ↓
┌─────────────────────────────────────┐
│  档位 < 注意值2 → 不适用            │
│  档位 ≥ 注意值2:                    │
│    ├─ 速率超注意 → 高·涨势快       │
│    ├─ 仅 H₂ 超标且速率未超 → 低 │
│    └─ 其他 → 中·暂稳               │
└─────────────────────────────────────┘
  ↓
输出: {level, advice, rising, h2_only}
```

### 3.2 涨势预警模型

```
涨势预警 = 月环比已超注意 且 档位仍为正常或注意值1
月环比超注意 = (总烃月环比 ≥ 10%/月) 且 (总烃 ≥ 10μL/L)
```

当日月环比超注意即认定，不加连续确认窗。

## 4 判型模型

### 4.1 三比值模型（ratios.py）

```
输入: h2, ch4, c2h4, c2h6, c2h2 (μL/L)
  ↓
┌──────────────────────────────────────┐
│  r1 = C₂H₂/C₂H₄ → 编码(0/1/2)      │
│  r2 = CH₄/H₂   → 编码(0/1/2)        │
│  r3 = C₂H₄/C₂H₆ → 编码(0/1/2)      │
│  查表7 → 故障类型                     │
│  映射 → Duval 分区代码                │
└──────────────────────────────────────┘
  ↓
输出: RatioResult{fault, code, ratios, duval_code, ok}
```

编码规则：


| 比值               | 编码 0         | 编码 1                    | 编码 2                  |
| ------------------ | -------------- | ------------------------- | ----------------------- |
| C₂H₂/C₂H₄ (r1) | <0.1           | 0.1～3（不含 3）          | ≥3                     |
| CH₄/H₂ (r2)      | <0.1 → 编为 1 | 0.1～1（不含 1）→ 编为 0 | ≥1 → 编为 2（非单调） |
| C₂H₄/C₂H₆ (r3) | <1             | 1～3（不含 3）            | ≥3                     |

前置门槛：五气**同时**低于各自地板才判数据不足——H₂/CH₄/C₂H₄/C₂H₆ 各 <10，C₂H₂ <1（μL/L）。

### 4.2 大卫三角模型（duval.py）

```
输入: ch4, c2h4, c2h2 (μL/L)
  ↓
┌────────────────────────────────────────┐
│  百分比坐标:                            │
│    %C₂H₂ = 100×C₂H₂/(CH₄+C₂H₄+C₂H₂) │
│    %C₂H₄ = 100×C₂H₄/(CH₄+C₂H₄+C₂H₂) │
│    %CH₄ = 100×CH₄/(CH₄+C₂H₄+C₂H₂)   │
│  分区判定 → PD/D1/D2/T1/T2/T3/DT      │
└────────────────────────────────────────┘
  ↓
输出: DuvalResult{zone, fault, percents, ok}
```

分区边界（附录C 表 C.1，按下表**顺序**判定，命中即返回）：


| 序 | 条件                                                  | 区域                    |
| -- | ----------------------------------------------------- | ----------------------- |
| 1  | %CH₄ ≥ 98%                                          | PD（局部放电）          |
| 2  | %C₂H₂ < 4% 且 %C₂H₄ < 10%                         | T1（热故障 <300℃）     |
| 3  | %C₂H₂ < 4% 且 10% ≤ %C₂H₄ < 50%                  | T2（热故障 300～700℃） |
| 4  | %C₂H₂ < 4% 且 %C₂H₄ ≥ 50%                         | T3（热故障 >700℃）     |
| 5  | %C₂H₂ < 15% 且 %C₂H₄ ≥ 50%                        | T3（热故障 >700℃）     |
| 6  | %C₂H₂ ≥ 13% 且 %C₂H₄ < 23%                       | D1（低能放电）          |
| 7  | %C₂H₂ ≥ 13% 且（%C₂H₄ ≤ 38% 或 %C₂H₂ ≥ 29%） | D2（高能放电）          |
| 8  | %C₂H₂ 13～29% 且 %C₂H₄ > 38%（右上折块）           | DT（放电兼过热）        |
| 9  | 其他（4% ≤ %C₂H₂ < 13% 的中间夹区）                | DT（放电兼过热）        |

D2 由表 C.1 四条极限线（23% C₂H₄ / 13% C₂H₂ / 38% C₂H₄ / 29% C₂H₂）围成的四边形，而非「≥23% 一刀切」——否则会把图 C.2 中 D+T 的右上折块误并进 D2。

**边界点归属**：落在分界线上的点归相邻两区中故障更严重的一区，严重度序 D2 > D1 > D+T > T3 > T2 > T1。故 %C₂H₂=13/29 归 D 类/D2、%C₂H₄=23/38 归 D2、%C₂H₂=4/15 归 D+T、%C₂H₄=10/50 归 T2/T3；唯 PD（%CH₄=98）按行业习惯取 ≥98（含线）。前端 Duval 图用离屏 Canvas 逐像素套同一套判定上色,图区与落区始终一致。

### 4.3 特征气体模型（key_gas.py）

```
输入: 7 气浓度
  ↓
┌───────────────────────────────────────────┐
│  入口门槛: 由判型页统一管理(注意值2+/涨势预警) │
│  表5 行匹配: 主气全检出 → 候选             │
│  注条件: 注2-3-5 CO₂/CO<3、注3 极少 C₂H₄、 │
│          注4 总烃<150                      │
│  多行命中: 取主气名单最全(最具体)的行      │
│  注1~5 定性附注(无乘子)                    │
└───────────────────────────────────────────┘
  ↓
输出: KeyGasResult{fault, nature, elevated, scores, ok,
                   primary, secondary, rows, note}
```

表3注意值的使用位置：

| 气体   | 注意值（μL/L） | 来源                 |
| ------ | --------------- | -------------------- |
| H₂    | 150             | DL/T 722-2014 表3；`elevated` 信息字段 |
| C₂H₂ | 5               | DL/T 722-2014 表3；`elevated` 信息字段 |
| 总烃   | 150             | DL/T 722-2014 表3；注4 火花「总烃不高」的判据（总烃<150 才候选火花） |
| CH₄/C₂H₆/C₂H₄ | —    | 表3无单项注意值；表5 匹配时按“检出”计（>0） |
| CO/CO₂ | —             | 表3无单项；含 CO 行以 CO₂/CO<3 佐证固体绝缘涉入 |

特征气体法判据全部锚定表5 正文 + 注1~5：
- 注1（油过热温区）：C₂H₄<C₂H₆→温度偏低、否则偏高；具体 300/700℃ 温区交三比值法表7
- 注2/注3/注5（固体绝缘）：含 CO 行（油和纸类）以 CO₂/CO<3 佐证
- 注3（局放）：主产 H₂/CH₄（H₂、CH₄ 占主导）且极少 C₂H₄（C₂H₄ 为四烃最少者）
- 注4（火花）：总烃不高——总烃<150（表3）才候选火花，≥150 更像电弧
- 注5（电弧）：主气 H₂/C₂H₂/C₂H₄ 齐全命中，原文未设总烃判据

## 5 交叉研判模型

### 5.1 模型结构

三方交叉核对 + 可信度标注：

```
输入: RatioResult + DuvalResult + KeyGasResult
  ↓
┌───────────────────────────────────────────────┐
│  ① 比值↔三角 落格一致性(pair_ok)              │
│     同格或相邻 → True; 否则 → False           │
│  ② 性质大类一致性(nature_agree)                │
│     过热/放电/混合 交叉核对                    │
│  ③ 主结论取名: Duval > 三比值 > 特征气体      │
│  ④ 表5 油/纸附注(paper_note)；仅 CO₂/CO<3 可增强，须 nature_agree 非 False │
│  ④′ 辅助比值其余 alert 只进 aux_ratios/reasoning，不改主结论 │
│  ⑤ 可信度判定 → 高/中/低                      │
│  ⑥ 试验建议 → 附录D + 1685 B.2/B.3            │
└───────────────────────────────────────────────┘
  ↓
输出: {primary, primary_code, nature, confidence, measures, ...}
```

### 5.2 一致性比对邻接表

```
T1: T1, T2, DT
T2: T1, T2, T3, DT
T3: T2, T3, D2, DT
PD: PD, D1
D1: PD, D1, D2, DT
D2: D1, D2, T3, DT
DT: D1, D2, T1, T2, T3, DT
```

### 5.3 可信度规则（与代码分支顺序一致，先命中者优先）

分档主轴 = **性质大类（放电/过热）**；三比值↔大卫三角分区代码落格只是同类内细分，权重更低。

| 条件                               | 可信度 | 说明                 |
| ---------------------------------- | ------ | -------------------- |
| 五烃均有值且均低于 10 μL/L        | 低     | 低浓度（§10.2.4 c） |
| 纯放电 vs 纯过热大类打架           | 低     | 性质不一致，一票否决 |
| 大类一致，且比值与三角落格同格/相邻 | 高     | 三方对齐             |
| 大类一致，但落格不一（同类内细分分歧） | 中     | 大类可信、细分待核实 |
| 含兼过热（mixed）+ 纯性质        | 中/低  | 编码相邻→中，否则→低 |
| 仅单一有效纯性质（nature_agree=None） | 中/低 | 编码相邻→中，否则→低 |

### 5.4 主结论取名（择优，非加权融合）

Duval > 三比值 > 特征气体。交叉研判是三法都算并核对一致性；主标题择优：大卫三角与三比值同属分区代码、可直接比落格，故二者有效时取大卫作主名；特征气体无官方分区代码映射，只作附注或兜底。

## 6 决策模型

### 6.1 模型结构

规则决策表模型，输入 5 维条件，输出 3 类决策 + 可解释轨迹：

```
输入: grade + is_pre + urgency + fusion(confidence) + rate_rising
  ↓
┌─────────────────────────────────────┐
│  条件匹配 → 周期档位               │
│  条件匹配 → 二次采样建议           │
│  条件匹配 → 试验建议               │
│  每步记录 trajectory              │
└─────────────────────────────────────┘
  ↓
输出: {period, resample, trials, trajectory, rules_fired, log}
```

### 6.2 决策规则表


| 条件                                      | 周期           | 二次采样     | 依据                    |
| ----------------------------------------- | -------------- | ------------ | ----------------------- |
| 正常或注意值1，且非涨势预警、速率未超     | 基线≤12h      | 不需要       | 1498-A.3.1 / 1498-5.4.5 |
| 涨势预警，或（注意值1 且速率超）          | 快速≤2h       | 建议二次采样 | 1498-5.5.5 / 1498-5.4.5 |
| 注意值2/告警 + 紧急度低                   | 基线+监视≤12h | 见下行       | 722-9.3.3 / 1498-5.4.5  |
| 注意值2/告警 + 紧急度高（月环比已超注意） | 快速≤2h       | 见下行       | 1498-5.5.5 / 1498-5.4.5 |
| 注意值2/告警 + 紧急度中（暂稳）           | 逼近≤2h       | 见下行       | 1498-A.3.1 / 1498-5.4.5 |

注意值2/告警下二次采样（与周期独立）：可信度**低** → 建议二次采样验证；可信度**高/中**或未进判型 → 暂不建议。

### 6.3 分类枚举

**周期分类**（供监测决策页归类）：


| 类别         | 文案                                 | 典型触发             |
| ------------ | ------------------------------------ | -------------------- |
| 基线         | 按在线基线周期(≤12h)                | 正常且速率未超       |
| 快速         | 缩短至最小检测周期(下限≤2h)         | 涨势预警，或紧急度高 |
| 基线加强监视 | 保持基线并加强监视(≤12h)            | 紧急度低             |
| 逼近快速     | 缩短检测周期并加强监视(建议逼近≤2h) | 紧急度中             |

**二次采样分类**：


| 类别   | 文案             | 典型触发             |
| ------ | ---------------- | -------------------- |
| 不需要 | 不需要           | 正常基线             |
| 建议   | 建议二次采样验证 | 涨势预警，或可信度低 |
| 暂缓   | 暂不建议二次采样 | 可信度高/中          |

## 7 工作流与报告表达

### 7.1 七步状态机

执行入口为 `pipeline.py`；`workflow.py` 负责计划与时间线辅助。

```
INIT → [1] ingest.load → [2] detect.grade → [3] trend.rate → [4] detect.urgency
     → [5] diagnose.fusion(可选) → [6] agent.decide → [7] agent.report → END
```

分支条件：注意值2/告警，或月环比超注意 / 涨势预警 → 进入步骤5；否则步骤5标记 skipped。

### 7.2 工具分层


| 层级 | 工具                                            | 说明                       |
| ---- | ----------------------------------------------- | -------------------------- |
| 感知 | 当日气体                                        | 读取当日七气浓度           |
| 分析 | 分级检测 / 产气趋势 / 处置紧急度 / 故障判型 | 国标规则判定               |
| 决策 | 监测决策                                        | 周期、二次采样、试验建议   |
| 表达 | 分析报告 / 助手解释润色                         | 报告成稿；助手解释类回复可选润色 |

### 7.3 大模型使用范围

可选调用 **阿里云北京 MaaS 上的通义千问 Max**，仅两处写人话，**不改变**档位 / 判型 / 阈值 / 决策：

1. **步骤 7 报告**：已算定事实 → 分析意见与试验成稿（`report_b`）；无密钥、强制模板、失败或校验不过 → 规则模板。
2. **分析助手解释润色**：规则解释草稿 → 口语化表述（`assistant/polish.py`）；失败回规则原文。触发完整分析仍走同一 `run_agent()`，助手不另设判型。

细则见《核心算法》报告意见与分析助手两节，以及正文 `第4章-分析智能体.md`、`第5章-预警管控系统.md`。
