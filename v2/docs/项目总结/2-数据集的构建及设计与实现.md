# 数据集的构建及设计与实现

## 1 概述

本系统业务库为 SQLite 文件 `v2/data/app.db`，业务表两张：


| 表             | 粒度                         | 说明                                              |
| -------------- | ---------------------------- | ------------------------------------------------- |
| `monitoring`   | 单台设备 × 360 天 DGA 日记录 | 全链路时序数据源                                  |
| `transformers` | 一台设备一行                 | 附录 G 表 G.1 铭牌/台账；演示 `transformer_id=1` |


| 层级                       | 名称 / 路径                         | 说明                                                    |
| -------------------------- | ----------------------------------- | ------------------------------------------------------- |
| 数据库文件                 | `v2/data/app.db`                    | SQLite                                                  |
| 业务表                     | `monitoring` / `transformers`       | ORM：`app/db/models.py` → `Monitoring` / `Transformer` |
| 原始原料（文件，非库表）   | `v2/data/raw/FinalDataSet_DGA.xlsx` | 743 条无时序快照，仅作合成分布原料                      |
| 合成中间文件               | `v2/data/synthetic_timeseries.csv`  | 入库前 CSV；列与`monitoring` 对齐                       |
| 测试数据集（文件，非库表） | `v2/data/test/*.json`               | 国标附录真值夹具；脚本直读，**不入库**                  |

---

## 2 数据从哪来（简述）

1. 公开集 bmrayan/DGA 的 743 条快照（7 气 + Fault 标签，**无日期**）→ 仅作分布原料。
2. `scripts.synthesize_data` 生成单台 × 360 天、7 气日时序（声明为在运设备）→ CSV。
3. `scripts.import_data` 写入 `monitoring`。
4. `scripts.seed_transformer` 写入演示铭牌台账（`transformers`，`transformer_id=1`，幂等）。

```bash
cd v2/BE && python -m scripts.init_db            # 建表（含 monitoring / transformers）
cd v2/BE && python -m scripts.synthesize_data    # → synthetic_timeseries.csv
cd v2/BE && python -m scripts.import_data        # → monitoring
cd v2/BE && python -m scripts.seed_transformer   # → transformers（已有则跳过）
```

## 3 业务表一览


| 表名           | 中文名                 | 行粒度                 | 用途                                                                |
| -------------- | ---------------------- | ---------------------- | ------------------------------------------------------------------- |
| `monitoring`   | 油中溶解气体监测日记录 | 一台设备 × 一个自然日 | 全链路时序源：分级 / 趋势 / 告警 / 判型 / 决策 / Agent / 数据集浏览 |
| `transformers` | 变压器设备台账         | 一台设备一行           | 附录 G 表 G.1 铭牌区；Agent 报告装配读取；**不参与**分级/判型计算   |

无用户表、无告警流水表、无报告存档表：告警列表与决策总览等均由算法对 `monitoring` **即时计算**后经 API 返回。铭牌缺记录时报告对应格填「—」。

## 4 表 `monitoring` 字段说明

### 4.1 建表要点

- 主键：`id`（自增）
- 唯一约束：`UNIQUE(transformer_id, date)`（`uq_tid_date`）——同一设备同一天只能一条
- 索引：`ix_monitoring_transformer_id`、`ix_monitoring_date`

### 4.2 字段字典


| 字段名           | 类型        | 单位  | 含义                                      | 谁用                                                 |
| ---------------- | ----------- | ----- | ----------------------------------------- | ---------------------------------------------------- |
| `id`             | INTEGER     | —    | 行号                                      | ORM / 内部                                           |
| `transformer_id` | INTEGER     | —    | 变压器设备编号；本演示恒为`1`（单台方案） | 查询过滤；与`transformers.transformer_id`对应        |
| `date`           | DATE        | —    | 监测日期，ISO`YYYY-MM-DD`；库内按日一条   | 全部模块按日取数；分级要求**日期升序**读入           |
| `h2`             | FLOAT       | μL/L | 氢气 H₂                                  | 表 A.3 浓度/增量落档；三比值；特征气体               |
| `ch4`            | FLOAT       | μL/L | 甲烷 CH₄                                 | 计入总烃；三比值；大卫三角；特征气体                 |
| `c2h4`           | FLOAT       | μL/L | 乙烯 C₂H₄                               | 计入总烃；三比值；大卫三角；特征气体                 |
| `c2h6`           | FLOAT       | μL/L | 乙烷 C₂H₆                               | 计入总烃；三比值；特征气体                           |
| `c2h2`           | FLOAT       | μL/L | 乙炔 C₂H₂                               | 表 A.3 浓度/增量落档；三比值；大卫三角；特征气体     |
| `co`             | FLOAT       | μL/L | 一氧化碳 CO                               | **不进**表 A.3 四档；供特征气体表5、辅助比值 CO₂/CO |
| `co2`            | FLOAT       | μL/L | 二氧化碳 CO₂                             | **不进**表 A.3 四档；供特征气体表5、辅助比值 CO₂/CO |
| `fault_state`    | VARCHAR(20) | —    | 合成真值标签：`Normal` / `放电` / `过热`  | **仅答辩/抽样对照**；不参与分级、不作为对外诊断结论  |

## 5 表 `transformers` 字段说明

演示台账：只填 DL/T 722 附录 G 表 G.1 **铭牌区**原有字段，不加非 G.1 内容。合成时序**不造**油温 / 负荷 / 取样原因与部位；绝对产气率式 1 仍缺油密度 → 报告对应格「—」。

### 5.1 建表要点

- 主键：`id`（自增）
- 业务键：`transformer_id`（UNIQUE）——与 `monitoring.transformer_id` 对齐；演示恒为 `1`
- ORM：`app/db/models.py` → `Transformer`
- 种子：`scripts.seed_transformer`（幂等，已有则跳过）

### 5.2 字段字典


| 字段名             | 类型        | 单位 | 含义（表 G.1） | 演示值示例        |
| ------------------ | ----------- | ---- | -------------- | ----------------- |
| `id`               | INTEGER     | —   | 行号           | —                |
| `transformer_id`   | INTEGER     | —   | 设备编号       | `1`               |
| `bureau`           | VARCHAR(40) | —   | 局（厂、所）   | 某供电公司        |
| `model`            | VARCHAR(60) | —   | 型号           | SFPSZ9-180000/220 |
| `voltage_capacity` | VARCHAR(60) | —   | 电压等级/容量  | 220kV / 180MVA    |
| `oil_weight_t`     | FLOAT       | t    | 油重           | 38.5              |
| `oil_type`         | VARCHAR(20) | —   | 油种           | 25号              |
| `manufacturer`     | VARCHAR(60) | —   | 制造厂         | 某变压器厂        |
| `serial_no`        | VARCHAR(40) | —   | 出厂序号       | SYN-001           |
| `manufacture_date` | VARCHAR(20) | —   | 出厂年月       | 2018-06           |
| `commission_date`  | VARCHAR(20) | —   | 投运日期       | 2018-12           |
| `cooling`          | VARCHAR(40) | —   | 冷却方式       | ONAN/ONAF         |
| `tap_changer`      | VARCHAR(40) | —   | 调压方式       | 有载              |
| `oil_protection`   | VARCHAR(40) | —   | 油保护方式     | 胶囊式            |

### 5.3 谁读、谁不读

- **读**：`/api/agent/run` 装配表 G.1 铭牌；报告预览 / PDF 导出展示。
- **不读**：`detect` / `trend` / `diagnose` / `warning` / `decision` 等判据链路——仍只吃 `monitoring` 时序。

## 6 原始快照（非库表，仅作合成原料）

文件：`v2/data/raw/FinalDataSet_DGA.xlsx`（公开集 bmrayan/DGA，743 条）。

### 6.1 字段对照


| 原始列名             | 入库短键 | 说明                 |
| -------------------- | -------- | -------------------- |
| Transformer（行号） | —        | 1~743 逐行编号，非真实设备编号，不可作台账标识 |
| Hydrogen (H2)        | `h2`     | 氢气                 |
| Methane (CH4)        | `ch4`    | 甲烷                 |
| Ethylene (C2H4)      | `c2h4`   | 乙烯                 |
| Ethane (C2H6)        | `c2h6`   | 乙烷                 |
| Acetylene (C2H2)     | `c2h2`   | 乙炔                 |
| Carbon Monoxide (CO) | `co`     | 一氧化碳             |
| Carbon Dioxide (CO2) | `co2`    | 二氧化碳             |
| Oxygen (O2) / Nitrogen (N2) | — | 采样点自带列，系统未采用 |
| Water (H2O)          | —        | 全列缺失，未采用     |
| Fault                | —        | 快照故障标签，无日期；仅 18/743 有值（No Fault 14 / Electrical Fault 2 / Thermal Fault 2） |

### 6.2 主要缺点（为何不能直接当业务库）


| 缺点                     | 影响                                                                                               |
| ------------------------ | -------------------------------------------------------------------------------------------------- |
| **无时间戳 / 无日期**    | 无法算表 A.3 增量与相对增长、无法算 722 总烃月环比；产气趋势 / 涨势预警 / 处置紧急度全部落空       |
| **无有效设备标识**       | Transformer 列为 1~743 逐行行号（非真实设备编号），无法区分台账；多台合成更假，故演示固定单台 |
| **未标电压等级**         | 表 A.3 阈值随电压档不同；系统自行声明「220kV 及以下」前提                                          |
| **CO / CO₂ 有缺失**     | 烃类较完整，CO 约缺 21.8%、CO₂ 约缺 31.4%；只作分布锚点统计，不填补后当主流程数据                     |
| **无油温 / 负载等工况**  | 合成仍不造工况；报告取样条件对应格填「—」                                                          |
| **无完整铭牌**           | 公开集无型号/油重等；本系统用`transformers`演示台账补表 G.1 铭牌区；绝对产气率仍缺油密度→「—」    |
| **故障标签稀疏**         | 仅 18/743（2.4%）有标签且偏粗（No Fault 14 / Electrical Fault 2 / Thermal Fault 2），真故障样本少，不宜当作多分类监督学习训练集 |

因此：原始快照**只作合成分布原料**；时序联调跑合成 360 天入库后的 `monitoring`；报告铭牌靠 `transformers` 演示台账。

## 7 测试数据集（文件，非库表）

路径：`v2/data/test/`。来源为行业标准原文色谱案例，**非合成**，用于算法真值对账；细则与结果见文档 5。


| 文件                            | 来源                         | 规模                | 用途                                       |
| ------------------------------- | ---------------------------- | ------------------- | ------------------------------------------ |
| `dlt722_appendix_e_cases.json`  | DL/T 722-2014 附录 E 表 E.4  | 17 组案例           | 验故障性质大类（过热 / 放电 / 放电兼过热） |
| `dlt1685_appendix_d_cases.json` | DL/T 1685-2017 附录 D 表 D.1 | 1 台 × 10 点长时序 | 验分级 + 趋势 / 紧急度口径                 |

**标注与存储格式：JSON。** 顶层均为 `_meta`（说明）+ `cases`（案例数组）；每个案例含若干 `records`（采样点）。

### 7.1 案例级字段字典

#### 附录 E（`dlt722_appendix_e_cases.json`）


| 字段名            | 类型   | 含义                                                                        |
| ----------------- | ------ | --------------------------------------------------------------------------- |
| `case_id`         | string | 案例编号，如`722-E-001`                                                     |
| `fault_cause`     | string | 原文故障原因摘要                                                            |
| `device_type`     | string | 设备类型（多为「变压器」）                                                  |
| `expected_nature` | string | 期望性质大类：`thermal` / `discharge` / `mixed`（按解体现象标注，非成因词） |
| `description`     | string | 原文检查 / 解体现象描述（对账依据）                                         |
| `records`         | array  | 该案例的色谱采样点列表（不规则日期）                                        |

#### 附录 D（`dlt1685_appendix_d_cases.json`）


| 字段名         | 类型   | 含义                                          |
| -------------- | ------ | --------------------------------------------- |
| `case_id`      | string | 案例编号，如`1685-D-001`                      |
| `device_model` | string | 设备型号，如`SFPSZ9-150000/220`               |
| `nature_note`  | string | 说明：原文无过热/放电性质结论，本案例不验性质 |
| `records`      | array  | 该案例的色谱采样点列表（不规则日期）          |

### 7.2 采样点 `records[]` 字段字典


| 字段名 | 类型   | 单位  | 含义                                                     |
| ------ | ------ | ----- | -------------------------------------------------------- |
| `seq`  | number | —    | 案例内采样序号（从 1 起）                                |
| `date` | string | —    | 采样日期，ISO`YYYY-MM-DD`（附录原文日期，非日连续）      |
| `h2`   | number | μL/L | 氢气 H₂                                                 |
| `ch4`  | number | μL/L | 甲烷 CH₄                                                |
| `c2h4` | number | μL/L | 乙烯 C₂H₄                                              |
| `c2h6` | number | μL/L | 乙烷 C₂H₆                                              |
| `c2h2` | number | μL/L | 乙炔 C₂H₂                                              |
| `co`   | number | μL/L | 一氧化碳 CO                                              |
| `co2`  | number | μL/L | 二氧化碳 CO₂                                            |
| `thc`  | number | μL/L | 原文总烃（以表内印刷值为准；与四烃加和偶有出入时不改表） |

### 7.3 为何用 JSON、不入库

测试需要的是**静态真值**，不是业务数据服务：脚本 `run_std_cases.py` 读 JSON 后直调 `detect` / `diagnose`，不经 HTTP/DB。

只有当你明确要做「前端点选附录案例跑演示」时，才值得考虑 API 读 JSON（或那时再建表）；那是**产品能力**，不是测试需要。

跑法（在 `v2/BE` 下）：`.venv/bin/python -m scripts.run_std_cases`。

## 8 说明

- 演示仍为**单台**（`transformer_id=1`）。若扩展多台：`monitoring` 靠 `transformer_id` 区分时序；每台再在 `transformers` 插一行铭牌；API 按 tid 过滤即可。
- 台账是演示声明项，不是现场实测铭牌；油温 / 负荷 / 绝对产气率（缺密度）仍诚实留空。
