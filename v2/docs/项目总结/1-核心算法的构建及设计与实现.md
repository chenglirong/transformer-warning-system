## 2 检测分级算法

### 2.1 功能

对每日 DGA 数据执行表A.3 三组判据分级（绝对浓度 / 绝对增量 / 相对增长速率），取最高档为当日综合档位；同时按 §9.3.2 计算总烃月环比，供处置紧急度、涨势预警与趋势展示。

### 2.2 输入


| 参数 | 类型           | 说明                                                                                                                               |
| ---- | -------------- | ---------------------------------------------------------------------------------------------------------------------------------- |
| `df` | `pd.DataFrame` | 日期升序；**必需** `date, h2, ch4, c2h4, c2h6, c2h2`（μL/L）。落档用乙炔 / H₂ / 总烃（总烃=四烃之和）。`co` / `co2` 不进表 A.3。 |

### 2.4 核心逻辑

#### 2.4.1 表A.3 三组判据

判档规则：达到某档**下限**即进入该档；**未达注意值1 下限即为正常**。表中「—」表示国标该档无定义（不再升档）。

**① 绝对浓度**（当日实测值）：


| 气体   | 正常   | 注意值1 | 注意值2 | 告警值 | 单位  |
| ------ | ------ | ------- | ------- | ------ | ----- |
| C₂H₂ | <1.0   | ≥1.0   | ≥5.0   | ≥8.0  | μL/L |
| H₂    | <120.0 | ≥120.0 | ≥150.0 | —     | μL/L |
| 总烃   | <120.0 | ≥120.0 | ≥150.0 | —     | μL/L |

**② 绝对增量**（γₐ = 当前值 − 参比值，公式 A.1）：


| 气体   | 正常  | 注意值1                 | 注意值2 | 告警值 | 单位      |
| ------ | ----- | ----------------------- | ------- | ------ | --------- |
| C₂H₂ | <1.0  | 「从无到有」或增量≥1.0 | ≥2.0   | ≥4.0  | μL/L·周 |
| H₂    | <15.0 | ≥15.0                  | ≥30.0  | —     | μL/L·周 |
| 总烃   | <15.0 | ≥15.0                  | ≥30.0  | —     | μL/L·周 |

**③ 相对增长速率**（仅总烃，γᵣ = (当前−参比)/参比×100%；总烃参比 <30 μL/L 时不计算此判据）：


| 气体 | 正常  | 注意值1 | 注意值2 | 告警值 | 单位 |
| ---- | ----- | ------- | ------- | ------ | ---- |
| 总烃 | <30.0 | ≥30.0  | ≥60.0  | —     | %/周 |

#### 2.4.2 参比值（A.3.3 a）

合成数据声明为**已稳定运行的在运设备**，参比**只走 A.3.3 a)**，不启用 b) 新投运特殊取法。

```python
# 窗口 = 前14天~前7天（两端含），Python 切片 [i-14, i-6)
# 先剔奇异值（超出 μ±2σ 的剔除），再算术平均
# 序列开头 lo<0：增量/增长率报「正常」并注「参比窗不足（前14天），暂不计算」
def _baseline(vals: list[float]) -> float | None:
    arr = pd.Series(vals, dtype=float)
    mu, sigma = arr.mean(), arr.std()
    if sigma > 0:
        kept = arr[(arr - mu).abs() <= 2.0 * sigma]
        if len(kept): arr = kept
    return float(arr.mean())
```

#### 2.4.3 综合档位

```python
grade = max(indicators, key=lambda x: GRADES.index(x["grade"]))
# 任一判据升档即升，取最高档
```

#### 2.4.4 月环比相对产气速率（§9.3.2 式2）

```python
# 今 vs 30天前，Δt=1月，直接 %/月
# 不做短窗折月放大（周环比×4.3 会导致健康段假超标）
thc_rel_rate = (thc_seq[i] - thc_seq[i-30]) / thc_seq[i-30] * 100.0
```

`thc_rel_rate` 算出后写入当日结果，并派生 `rate_rising` / `is_pre`，再进入紧急度研判；趋势 API 将其映射为 `rel_rate` 画曲线。

#### 2.4.5 处置紧急度研判（§9.3.3）

仅注意值2+启动，**不改已落定档位**（档位仍按表A.3）：


| 条件                                                      | 紧急度 | 说明                                                                                                       |
| --------------------------------------------------------- | ------ | ---------------------------------------------------------------------------------------------------------- |
| 总烃月环比已超注意（≥10%/月）                            | 高     | 「涨势快」：含量已注意，产气仍在明显上涨，宜缩短检测周期                                                   |
| 仅 H₂ 相关判据超标（乙炔、总烃均正常），且月环比未超注意 | 低     | **仅 H₂ 超标且速率未超**：档位仍如实报，紧急度降为低，建议加强监视 |
| 其他注意值2+（含量超但月环比未超）                        | 中     | 「暂稳」：已达含量注意，涨势不猛，加强监视                                                                 |

### 2.5 运行示例

输入某日数据：H₂=4.8, CH₄=65.5, C₂H₄=19.7, C₂H₆=16.6, C₂H₂=0.7, CO=243.0, CO₂=1226.6

- 总烃绝对浓度 ≈102.6 μL/L → **正常**（<120）
- 绝对增量·总烃 ≈54.6 μL/L·周 → **注意值2**（≥30）
- 相对增长速率·总烃 ≈113.8 %/周 → **注意值2**（≥60；该判据告警档无定义，不再升）

综合档 = **注意值2**。若月环比已超注意 → 紧急度=高·涨势快。

### 3.1 三比值法（ratios.py）

#### 功能

按 DL/T 722-2014 §10.2 表6 编码 + 表7 查表判型。

#### 输入

5 烃类标量（μL/L）：`h2, ch4, c2h4, c2h6, c2h2`。

#### 输出

`RatioResult`：


| 字段         | 类型     | 说明                                         |
| ------------ | -------- | -------------------------------------------- |
| `method`     | `str`    | `"三比值法"`                                 |
| `fault`      | `str`    | 故障类型或「数据不足」/「无对应编码」        |
| `code`       | 可选元组 | `(r1, r2, r3)` 编码；序列化时为 list         |
| `ratios`     | `dict`   | `C2H2/C2H4` / `CH4/H2` / `C2H4/C2H6`         |
| `duval_code` | 可选 str | 工程映射到三角标签 PD/D1/D2/T1/T2/T3/DT（供一致性对照） |
| `ok`         | `bool`   | 是否给出有效判型                             |
| `reason`     | 可选 str | 失败原因（缺气 / 过低 / 除零 / 编码不在表7） |

#### 编码规则（表6，半开区间与代码一致）


| 比值               | 编码规则                               |
| ------------------ | -------------------------------------- |
| C₂H₂/C₂H₄ (r1) | <0.1→0；[0.1, 3)→1；≥3→2           |
| CH₄/H₂ (r2)      | <0.1→1；[0.1, 1)→0；≥1→2（非单调） |
| C₂H₄/C₂H₆ (r3) | <1→0；[1, 3)→1；≥3→2               |

分母接近 0（工程上视为除不尽）→ 该比值不计算 → 整条判为「无对应编码」、无效。

#### 表7 编码→故障类型→大卫三角（工程对照，国标无官方映射表）


| 编码                        | 故障类型          | 三角标签 | 对应理由 |
| --------------------------- | ----------------- | -------- | -------- |
| (0,0,0)                     | 低温过热<150℃    | T1       | 三角 T1 为 t&lt;300℃；表7把低温拆两档，对照时并回 T1 |
| (0,2,0)                     | 低温过热150~300℃ | T1       | 落在 T1 温区 |
| (0,2,1)                     | 中温过热300~700℃ | T2       | 与 T2 温区一致 |
| (0,0,2) / (0,1,2) / (0,2,2) | 高温过热>700℃    | T3       | 与 T3 温区一致 |
| (0,1,0)                     | 局部放电          | PD       | 名称与机理一致 |
| (2,0,*) / (2,1,*)           | 低能放电          | D1       | 低能量放电 |
| (2,2,*)                     | 低能放电兼过热    | DT       | 「兼过热」=放电+过热，对三角 D+T 混合区 |
| (1,0,*) / (1,1,*)           | 电弧放电          | D2       | 表7「电弧」≈三角「高能放电」 |
| (1,2,*)                     | 电弧放电兼过热    | DT       | 同上，对 D+T |

其余未列出的编码 →「无对应编码」。页面仍显示表7中文原文；`duval_code` 仅用于与三角落区比同格/相邻。

### 3.2 大卫三角形法（duval.py）

#### 功能

按 DL/T 722-2014 附录C 图C.2 / 表C.1 百分比坐标落区。

#### 输入

`ch4, c2h4, c2h2`（μL/L）。缺气或三气之和接近 0 → 数据不足。

#### 输出

`DuvalResult`：


| 字段       | 类型     | 说明                                |
| ---------- | -------- | ----------------------------------- |
| `method`   | `str`    | `"大卫三角形法"`                    |
| `zone`     | 可选 str | PD / D1 / D2 / T1 / T2 / T3 / DT    |
| `fault`    | `str`    | 中文标签                            |
| `percents` | `dict`   | `pct_c2h2` / `pct_c2h4` / `pct_ch4` |
| `ok`       | `bool`   | 是否有效                            |
| `reason`   | 可选 str | 失败原因                            |

#### 坐标计算（附录C 式 C.1–C.3）

令 \(X\)=C₂H₂、\(Y\)=C₂H₄、\(Z\)=CH₄（含量，μL/L），三气百分比：


| 公式   | 计算                       |
| ------ | -------------------------- |
| 式 C.1 | %C₂H₂ = 100·X / (X+Y+Z) |
| 式 C.2 | %C₂H₄ = 100·Y / (X+Y+Z) |
| 式 C.3 | %CH₄ = 100·Z / (X+Y+Z)   |

#### 区域极限（附录C 表 C.1）

落区按表 C.1 极限线；D2 为四条极限线围成的四边形，图 C.2 中 D2 右上被折出的一小块与其余未落入热/放电区的中间区合记为 **DT**（表中未单列）。


| 故障区                 | 极限1                        | 极限2      | 极限3      | 极限4      |
| ---------------------- | ---------------------------- | ---------- | ---------- | ---------- |
| PD（局部放电）         | 98% CH₄                     | —         | —         | —         |
| D1（低能放电）         | 23% C₂H₄                   | 13% C₂H₂ | —         | —         |
| D2（高能放电）         | 23% C₂H₄                   | 13% C₂H₂ | 38% C₂H₄ | 29% C₂H₂ |
| T1（热故障 <300℃）    | 4% C₂H₂                    | 10% C₂H₄ | —         | —         |
| T2（热故障 300~700℃） | 4% C₂H₂                    | 10% C₂H₄ | 50% C₂H₄ | —         |
| T3（热故障 >700℃）    | 15% C₂H₂                   | 50% C₂H₄ | —         | —         |
| DT（放电兼过热）       | 上述未覆盖的中间区（图 C.2） |            |            |            |

实现上按表 C.1 极限**顺序落区**（`classify_zone`）：先 PD（CH₄≥98%）；再判纯热竖线 C₂H₂<4% 内按乙烯 10%·50% 分 T1·T2·T3；再判 T3（C₂H₂<15% 且 C₂H₄≥50%）；再判放电 C₂H₂≥13%（乙烯 23% 分 D1·D2，D2 由 23%/13%/38%/29% 四条极限围成，C₂H₄>38% 且 C₂H₂<29% 的右上折块归 D+T）；其余（4%≤C₂H₂<13%）为 DT。

**边界点归属**：落在分界线上的点归相邻两区中故障更严重的一区，严重度序 D2 > D1 > D+T > T3 > T2 > T1。据此 C₂H₂=13/29 归 D 类/D2、C₂H₄=23/38 归 D2、C₂H₂=4/15 归 D+T、C₂H₄=10/50 归 T2/T3；唯 PD（CH₄=98）按行业习惯取 ≥98（含线）。前端 Duval 图用离屏 Canvas 逐像素调用同一套 `classifyZone` 上色，保证图区与落区判定始终一致。

| C₂H₂ | 5（220kV及以下） | ≥5（借表3注意值）    | DL/T 722-2014 表3   |
| 总烃   | 150             | —（仅注4火花/电弧分档用） | DL/T 722-2014 表3   |
| CH₄/C₂H₆/C₂H₄ | —    | 检出>0（表3无注意值，不自造门槛） | — |
| CO/CO₂ | —             | `need_co` 行以 CO₂/CO<3 佐证固体绝缘涉入 | — |

> **检出门槛为何借表3**：表5 只给定性名单、未给单气体下限。若一律按 >0 判检出，高温过热样本里只要有一丁点 C₂H₂ 就会误命中「油中电弧」等放电行，让融合层平白出现「放电 vs 过热」假分歧。故对表3 已列注意值的主气（H₂≥150、C₂H₂≥5@220kV）借其注意值当检出线；表3 未列注意值的 CH₄/C₂H₄/C₂H₆ 不自造门槛，仍按 >0。此为工程取值，非表5 原文。

#### 匹配规则

- **入口统一**：是否进入判型已由判型页统一管理（注意值2/告警或涨势预警）；`key_gas.py` 内部不再单独复检表3
- **行命中**：某行主要特征气体（除 CO）全部“检出”即为候选——检出门槛见上表（H₂≥150、C₂H₂≥5 借表3注意值，CH₄/C₂H₄/C₂H₆ 按>0）
- **含 CO 行（油和纸类 2/3/6）**：另需 CO₂/CO<3 佐证固体绝缘涉入；单点浓度无法区分是新产气还是老龄积累，故用比值（量纲无关、单点可算），不依赖基线/产气速率
- **注条件区分**：
  - 注1：油过热按温度分档——C₂H₄≤C₂H₆ 倾向中低温（<300℃），C₂H₄ 多于 C₂H₆ 倾向较高温度；本行自持，不借三比值
  - 注3：局放“以极少 C₂H₄ 为特征”且“主产 H₂/CH₄”——C₂H₄ 须为四烃中最少者，且 H₂、CH₄ 均不低于其余烃气（占主导）；任一不满足即排除该行（纯相对比较，无固定阈值）
  - 注4/注5：火花 vs 电弧以总烃 150（表3 总烃注意值）为界，总烃<150 倾向火花、≥150 倾向电弧
- **多行命中定夺**：取表5 主气名单**最全（最具体）**的那行为结论——表5 六行主气名单嵌套（火花 H₂/C₂H₂ ⊂ 电弧 H₂/C₂H₂/C₂H₄ ⊂ 油和纸中电弧 +CO），主气越全＝特征气体越齐＝命中越具体；其余命中行作候选附注，细分建议结合三比值/大卫三角
- **逐行明细**：`rows` 返回六行 `matched/chosen/reject`，前端可展示“命中行+落选原因”对照
- **注1~5**：作为定性附注附加于 `note` 字段，不改变匹配结果
- 烃类有效值不足 3 个、或无行匹配 → `ok=False`

### 3.4 多方法交叉研判（fusion.py）

#### 输入

`RatioResult`、`DuvalResult`、`KeyGasResult`；可选 `gases`（辅助比值）；`low_concentration`。

#### 主结论取名（择优，非加权融合）

交叉研判 = 三法都算 + 落格/性质交叉核对定可信度；主标题只选一个写法：

1. Duval 有效 → 用其 `fault` / `zone` 作 `primary` / `primary_code`
2. 否则三比值有效 → 用其故障名与映射分区代码
3. 否则特征气体有效 → 用表5 原文（**无**分区代码）
4. 否则「无法判定」

特征气体**不硬翻**分区代码；油/纸维度只进 `paper_scope` / `paper_note`。

#### 输出核心字段


| 字段                               | 说明                                                                                              |
| ---------------------------------- | ------------------------------------------------------------------------------------------------- |
| `primary` / `primary_code`         | 主结论与分区代码（特征气体兜底时 code 为`None`）                                                    |
| `nature` / `nature_label`          | thermal / discharge / mixed / unknown 及其中文                                                    |
| `nature_agree`                     | 放电 vs 过热大类是否一致（`True`/`False`/`None`）                                                 |
| `ratio_duval_consistent`           | 三比值映射码与三角区同格或相邻（见下表）                                                          |
| `confidence` / `confidence_reason` | 高 / 中 / 低 + 原因                                                                               |
| `provisional` / `stance`           | 可信度低则为暂定（`provisional` / `adopted`）                                                     |
| `paper_scope` / `paper_note`       | 油纸附注；大类分歧时`_paper_annot` 抑制                                                           |
| `aux_ratios`                       | `{co2_co, c2h2_h2, o2_n2, notes}`                                                                 |
| `reasoning`                        | 链路短句（三方法 + 全部辅助比值 notes，含`cite`）                                                 |
| `measures*`                        | 附录D / 1685 试验包（`measures`、`measures_appendix_d`、`measures_1685*`、`measures_purpose` 等） |
| `summary`                          | 一句话摘要（Agent / 日志）                                                                        |

#### 可信度判定（与代码分支顺序一致）

下列条件按代码从上到下匹配，**先命中者优先**。


分档主轴 = **性质大类（放电/过热）**——它决定试验方向、最稳；三比值↔大卫三角的分区代码落格只是同一大类内的细分（温区/能级），权重更低。下列条件按代码从上到下匹配，先命中者优先。

| 条件                                 | 可信度 | 白话含义                                                                                                                                                                   |
| ------------------------------------ | ------ | -------------------------------------------------------------------------------------------------------------------------------------------------------------------------- |
| 五烃浓度整体偏低                     | 低     | 参与判型的 H₂/CH₄/C₂H₄/C₂H₆/C₂H₂**均有值且均低于 10 μL/L**（§10.2.4 c）。气体太淡，编码参考价值有限，结论标「暂定」。对应 `low_concentration=True`。 |
| 纯放电 vs 纯过热打架                 | 低     | 各法里有的指向**纯过热**、有的指向**纯放电**，无法归入同一性质大类。对应 `nature_agree=False`。                                                        |
| 大类一致（agree=True）且落格同格/相邻 | 高    | 过热/放电方向一致，且三比值↔大卫三角分区代码同格或相邻。三方强吻合。                                                                                                       |
| 大类一致（agree=True）但落格不一     | 中     | 大类对齐，但两法落到不相邻的代码（如 T1 vs T3，同为过热、温区不同）。大类可信、细分待核实。                                                                                |
| 综合性质为兼过热（含放电成分）       | 中/低  | 有方法判「兼过热」+ 有方法判纯性质：编码相邻→中，否则→低。含放电成分，不上高。                                                                                              |
| 其余（仅一方给出有效纯性质，线索单薄） | 中/低 | `nature_agree=None`：编码相邻→中，否则→低。                                                                                                                                |

`nature_agree` 取值：`True`=大类一致；`False`=纯放电 vs 纯过热分歧；`None`=兼过热或仅一方给出有效纯性质、无法两票表决。

> **为何编码落格不一只降到「中」而非「低」**：只要落格不一时两法仍同属一个大类（都过热或都放电），代码差异只是同类内温区/能级的细分分歧，试验方向不变，故取中；只有性质大类真打架（放电 vs 过热）才一票否决到低。

#### 分区代码相邻关系（同格或相邻 → 一致）


| 区 | 相邻集合（含自身）     |
| -- | ---------------------- |
| PD | PD, D1                 |
| D1 | PD, D1, D2, DT         |
| D2 | D1, D2, DT, T3         |
| T1 | T1, T2, DT             |
| T2 | T1, T2, T3, DT         |
| T3 | T2, T3, D2, DT         |
| DT | D1, D2, T1, T2, T3, DT |

大类打架时，试验建议仍可按主结论分区代码映射过热/放电性质给附录D（不下成因）。

### 3.5 辅助比值（auxiliary_ratios.py）

#### 功能

§10.2.3 三组辅助比值，**不改变**主结论分区代码 / nature / confidence。

#### 输入

`{co2, co, c2h2, h2, o2, n2}`。当前 `diagnose_sample` 传入七气时**不含 O₂/N₂**，故 O₂/N₂ 条一般不触发；接口预留。

#### 判据


| 比值       | 条件 | level       | 含义                       | clause   |
| ---------- | ---- | ----------- | -------------------------- | -------- |
| CO₂/CO    | <3   | alert       | 故障可能涉及固体绝缘       | 10.2.3.1 |
| CO₂/CO    | >7   | info        | 属正常老化范围             | 10.2.3.1 |
| CO₂/CO    | 3~7  | （无 note） | 正常区间，不产附注         | —       |
| C₂H₂/H₂ | >2   | alert       | 有载分接开关油可能渗入本体 | 10.2.3.2 |
| O₂/N₂    | <0.3 | alert       | 密封可能有问题             | 10.2.3.3 |

除零：CO=0 或 H₂=0 或 N₂=0 时对应比值不计算。`ok=True` 表示**产出了至少一条 note**（不是「算出了比值」）。

#### 与结论层边界

- **`paper_note`**：仅允许 `CO₂/CO <3` 的 alert 并入（与油纸语义一致）；`C₂H₂/H₂`、`O₂/N₂` 只进 `aux_ratios.notes` 与 `reasoning`
- **`paper_scope` 升格为 oil_paper**：须 `nature_agree is not False`，且存在 CO₂/CO<3
- **cite**：note 的 `clause` 为 `10.2.3.x`；交叉研判层写成 `722-10.2.3.x`，与知识库 / 前端 `STD_REFS` 对齐

## 4 监测决策算法

### 4.1 功能

基于档位 / 涨势预警 / 紧急度 / 交叉研判可信度，输出**检测周期**文案、二次采样**建议**、其他检查性试验清单及可解释轨迹（UI/日志统称「检测周期」；角标区分 A.3.1 数据采集周期与 §5.5.5 最小检测周期）。

### 4.2 输入


| 参数          | 类型      | 说明                         |
| ------------- | --------- | ---------------------------- |
| `grade`       | `str`     | 检测档位                     |
| `is_pre`      | `bool`    | 涨势预警                     |
| `urgency`     | 可选 dict | 处置紧急度                   |
| `fusion`      | 可选 dict | 交叉研判结果（可信度与试验） |
| `rate_rising` | `bool`    | 月环比超注意                 |

### 4.3 输出


| 字段                                                                               | 说明                                                                                                                                       |
| ---------------------------------------------------------------------------------- | ------------------------------------------------------------------------------------------------------------------------------------------ |
| `period` / `period_why`                                                            | 检测周期文案与原因                                                                                                                         |
| `resample` / `resample_why`                                                        | 二次采样文案与原因                                                                                                                         |
| `trials`                                                                           | 试验建议列表（来自交叉研判的 measures）                                                                                                    |
| `trials_purpose`                                                                   | 试验清单语气：`verify`=暂定结论、试验侧重**核实**；`recommend`=非暂定、可按结论**采纳**推荐。与 `fusion.provisional`（可信度低→暂定）联动 |
| `trials_basis` / `trials_appendix_d` / `trials_1685_items` / `trials_nature_label` | 试验依据与附录拆分                                                                                                                         |
| `cite_period` / `cite_resample`                                                    | 依据条目 id（前端 StdCite）                                                                                                                |
| `trajectory`                                                                       | `{condition, action, cite, field}` 决策轨迹                                                                                                |
| `rules_fired`                                                                      | `条件 → 动作` 字符串列表                                                                                                                  |
| `log`                                                                              | 一句话摘要                                                                                                                                 |
| `resample_note`                                                                    | 二次采样由装置/运维执行的说明                                                                                                              |
| `offline_note`                                                                     | 离线例行周期对照说明（不写入在线主规则）                                                                                                   |

`baseline`（基线≤12h）、`fast`（最小检测周期≤2h）、`baseline_watch`（保持基线加强监视）、`approach_fast`（逼近快速）；`none`（不需二次采样）、`suggest`（建议二次采样）、`defer`（暂不建议）。**不参与判据计算**。

### 4.4 决策规则

分支顺序与代码一致：


| 条件                                                      | 周期文案                             | 二次采样         | 周期依据   |
| --------------------------------------------------------- | ------------------------------------ | ---------------- | ---------- |
| 正常或注意值1，且非涨势预警、速率未超                     | 按在线基线周期(≤12h)                | 不需要           | 1498-A.3.1 |
| 涨势预警，或（注意值1 且速率超）                          | 缩短至最小检测周期(下限≤2h)         | 建议二次采样验证 | 1498-5.5.5 |
| 注意值2/告警 + 紧急度**低**（仅 H₂ 超标且速率未超）       | 保持基线并加强监视(≤12h)            | 见下行可信度分支 | 722-9.3.3  |
| 注意值2/告警 + 紧急度**高**（总烃月环比已超注意，涨势快） | 缩短至最小检测周期(下限≤2h)         | 见下行可信度分支 | 1498-5.5.5 |
| 注意值2/告警 + 紧急度**中**（含量已注意、涨势暂稳）       | 缩短检测周期并加强监视(建议逼近≤2h) | 见下行可信度分支 | 1498-A.3.1 |

注意值2/告警下的二次采样（与周期独立，看交叉研判可信度）：

- 可信度**低**（暂定 / 方法分歧）→ **建议二次采样验证**（由装置或运维核实，本系统只出建议）
- 可信度**高**或**中**（或未进判型、无 fusion）→ **暂不建议二次采样**

二次采样依据条目固定为 `1498-5.4.5`。有试验清单时轨迹再挂一条「其他检查性试验 N 项」→ `722-附录D`。

## 5 工作流编排

### 5.1 职责划分


| 文件           | 职责                                                                                |
| -------------- | ----------------------------------------------------------------------------------- |
| `tools.py`     | 工具注册表`TOOL_SPECS` + 统一观测包 `make_observation`                              |

| `run_logs.py`  | 从 `steps` 展开可审计运行日志 `log_lines`（前端流式渲染；`steps[].log` 仍为一句摘要） |

工具内部全是规则/查表。LLM **不改档位/类型/决策数值**，仅两处写人话：① 报告意见（`report_b.generate_opinion`）；② 助手解释类回复润色（`assistant/polish.py`）。失败均回退规则原文/模板。分析助手细节见 §7。

### 5.2 七步顺序

```
INIT → ingest.load → detect.grade → trend.rate → detect.urgency
     → diagnose.fusion（未达门槛则 skip）→ agent.decide → agent.report → END
```

**进入判型**：注意值2+，或 `rate_rising` / 涨势预警（`eligible_for_diagnose` 把 `is_pre` 并入速率条件）。

### 5.3 工具注册表


| 工具名            | 标签         | 层级     | 说明                                           |
| ----------------- | ------------ | -------- | ---------------------------------------------- |
| `ingest.load`     | 当日气体     | perceive | 读取指定日 DGA 七气浓度                        |
| `detect.grade`    | 分级检测（UI）/ 四档落档 | analyze  | 表A.3 三组取最高档；步骤名「分级检测」         |
| `trend.rate`      | 产气趋势                 | analyze  | §9.3.2 总烃月环比（涨势预警 / 涨势快 / 未超） |
| `detect.urgency`  | 处置紧急度               | analyze  | 仅注意值2+ 研判                                |
| `diagnose.fusion` | 故障判型（UI）           | analyze  | 多方法交叉研判；未达门槛执行 skip              |
| `agent.decide`    | 监测决策     | decide   | 周期 / 采样建议 / 试验                         |
| `agent.report`    | 分析报告     | express  | 表G.1/G.2 事实打包 + 意见文本（LLM 或模板）    |

前端步骤条展示顺序可能把「产气趋势」排在紧急度附近，但**执行顺序以上述状态机为准**。

## 6 报告意见生成

**定位**：工作流第七步「表达层」——把前面**已算定的**档位、趋势、紧急度、交叉研判、监测决策，写成附录 G 的**分析意见**（G.1）与**其他检查性试验**成稿（G.2）。

**红线**：LLM **只写人话**，不参与任何判据；档位 / 故障类型 / 可信度 / 周期 / 试验清单一律照抄事实包。失败则降级为规则模板，系统仍可出报告。

### 6.1 何时启用 LLM


| 条件                          | 行为                                                  |
| ----------------------------- | ----------------------------------------------------- |
| 未配置`LLM_API_KEY`           | 直接用规则模板，`mode=rule_template`                  |
| 调用方传`force_template=True` | 强制模板（联调/答辩可关 LLM）                         |
| 已配置密钥且未强制模板        | 调通义千问（阿里云 MaaS）；失败或校验不过 → 回退模板 |

客户端（`llm_client.py`）按环境变量请求阿里云 Chat Completions。本机 `.env`：


| 变量           | 本机取值                               | 说明             |
| -------------- | -------------------------------------- | ---------------- |
| `LLM_API_KEY`  | （本地密钥，不入库）                   | 有值才启用       |
| `LLM_BASE_URL` | 阿里云北京 MaaS`…/compatible-mode/v1` | 通义千问托管网关 |
| `LLM_MODEL`    | `qwen-max`                             | 通义千问 Max     |

本系统实际使用 **qwen-max（阿里云北京 MaaS）**。请求路径 `{BASE_URL}/chat/completions`；回包支持标准 `choices[].message.content` 与部分扁平 `text` 结构。

### 6.2 输入：中文事实包

`pipeline` 先把当日结果收成 `facts`，再经 `_facts_for_llm` **改成中文键名**再送给模型（避免模型把 `confidence` / `provisional` 等英文字段抄进正文）。主要内容包括：

- 当日最高档、超标项、七气浓度、总烃
- 是否涨势预警、总烃月环比、处置紧急度
- 是否已触发判型、主结论、编码、可信度、是否暂定、故障性质、研判要点
- 建议检测周期、二次采样安排、试验项目清单
- 可选：油纸附注、非故障气源提示

### 6.3 提示词约束（系统侧）

角色：电力试验室工程师，写正式报告语气。硬约束摘要：

1. **标准不许串**：四档只挂 1498.2 表 A.3；产气速率 / 涨势挂 722 §9.3.2·§9.3.3；类型挂 722 §10；试验挂附录 D（+1685 B）。
2. **只复述、不改判**：禁止改档位 / 类型 / 可信度；禁止发明气体数据、试验项、运维指令（如「立即停电」）。
3. **结构固定**：分析意见须含【告警级别】【趋势】【处置紧急度】【故障类型】或【暂定故障类型】【处置建议】；各区段落衔接，禁止电报体堆字段。
4. **输出纯 JSON**：`{"opinion":"...","other_tests":"..."}`；角标【n】由流水线后填，模型不要自加。

### 6.4 生成与校验流程

```
facts → 规则模板（底稿）
      →（可选）LLM 润色 → JSON 解析
      → 校验 opinion / other_tests
      → 不过则该项回退模板
      → 补非故障气源提示（若有）→ 定稿
```

**分析意见校验**（节选）：须含固定分区标签；篇幅不能过短；档位须出现；禁「立即停电 / 100%确诊」等；禁止英文键名泄漏；四档不得误挂到「722」。

**试验成稿校验**（节选）：有清单时须覆盖大部分试验原名；须写出故障性质；禁「已开展 / 已完成」；须含「建议/宜」语气。

**输出字段**：`text`、`other_tests`、`mode`（`llm` / `rule_template`）、可选 `error` / `note`。流水线再按章节挂依据角标。

### 6.5 规则模板降级

无密钥 / 强制模板 / LLM 失败 / 校验失败时，用 `build_template_opinion`、`build_template_other_tests` 按同一分区结构填空成长文。保证**离线也可出完整报告**；LLM 的增益主要是因果衔接与工程表述，不是另出一套结论。

### 6.6 与核心算法的关系


| 层级 | 模块                       | 做什么                           |
| ---- | -------------------------- | -------------------------------- |
| 判据 | detect / diagnose / decide | 算档位、类型、可信度、周期、试验 |
| 表达 | report_b（+ 可选 LLM）     | 把结果写成报告用语               |
| 交互 | assistant（规则解释 + 可选润色） | 对话触发/追问；判定仍走 `run_agent()` |
| 版式 | report_export（另文）      | PDF 排版导出，不参与分析         |

## 7 分析助手（交互层）

**定位**：挂在 Agent 页抽屉，**不是**第二套诊断。完整分析一律调用同一 `run_agent()`；追问走规则模板解释 + 角标；FAQ 关键词匹配。

**链路**：意图识别（`intent.py`）→ 规则解释 / FAQ（`explain.py` / `fallback.py`）→ 可选 LLM 润色（`polish.py`，校验失败回规则原文）→ 会话状态（`session.py`，含主区 `sync`）。

**红线**：不改档位 / 故障类型 / 数值 / 试验清单；报告成稿仍仅由 §6 报告模块承担。界面与双向联动见正文 `第4章-分析智能体.md`、`第5章-预警管控系统.md`。
