# 接口文档

## 1 概述

- **交互方式**：监测原始数据入库后，分级 / 趋势 / 告警 / 判型 / 决策等结果由接口**实时计算**返回（不另建结果表）
- **统一信封**（JSON 业务接口）：`{ status, code, message, data }`；成功时 `status=code=200`。下文「返回」均指 `data` 内结构
- **例外**：报告导出接口直接返回文件流（非信封）

| `records[].c2h6` | `float 或 null` | 乙烷 C₂H₆（μL/L）               |
| `records[].c2h2` | `float 或 null` | 乙炔 C₂H₂（μL/L）               |
| `records[].co`   | `float 或 null` | 一氧化碳 CO（μL/L）             |
| `records[].co2`  | `float 或 null` | 二氧化碳 CO₂（μL/L）            |

## 4 检测 detect

### 4.1 GET `/api/detect/series`

全年日历色带，**检测 / 判型 / Agent 三页共用**（不再另设 `/diagnose/series`、`/agent/series`）。


| 字段                   | 类型     | 含义                                                              |
| ---------------------- | -------- | ----------------------------------------------------------------- |
| `series`               | `array`  | `[{ date, grade, is_pre }]`，`grade`∈正常/注意值1/注意值2/告警值 |
| `summary.default_date` | `string` | 三页共用默认日：最近可进判型日；若无则末日                       |

### 4.2 GET `/api/detect/day/{day}`

单日表 A.3 指标 + 月环比 + 紧急度。


| 字段                     | 类型             | 含义                      |
| ------------------------ | ---------------- | ------------------------- |
| `date`                   | `string`         | 监测日                    |
| `grade`                  | `string`         | 综合最高档                |
| `is_pre`                 | `bool`           | 涨势预警                  |
| `rate_rising`            | `bool`           | 总烃月环比是否超注意      |
| `thc_rel_rate`           | `float 或 null`  | 总烃月环比（%/月）        |
| `thc_rel_rate_attention` | `float`          | 注意阈值（10）            |
| `urgency`                | `object 或 null` | 处置紧急度，见下          |
| `indicators`             | `array`          | 表 A.3 全部指标（含正常） |

**urgency**：


| 字段      | 类型     | 含义            |
| --------- | -------- | --------------- |
| `level`   | `string` | 高 / 中 / 低    |
| `advice`  | `string` | 人话说明        |
| `rising`  | `bool`   | 速率是否超注意  |
| `h2_only` | `bool`   | 仅 H₂ 超标且速率未超 |

**indicators[]**：


| 字段       | 类型             | 含义                                                                 |
| ---------- | ---------------- | -------------------------------------------------------------------- |
| `basis`    | `string`         | 绝对浓度 / 绝对增量 / 相对增长速率                                   |
| `gas`      | `string`         | `c2h2` / `h2` / `total_hydrocarbon`                                  |
| `item`     | `string`         | 中文名                                                               |
| `unit`     | `string`         | μL/L · μL/L·周 · %/周                                           |
| `value`    | `float 或 null`  | 本指标数值                                                           |
| `grade`    | `string`         | 本指标档位                                                           |
| `bounds`   | `object`         | `{ 注意值1, 注意值2, 告警值 }`                                       |
| `baseline` | `float 或 null`  | 参比值（前14～前7天窗口均值）；绝对浓度无此字段，增量/速率用其算「当前−参比」 |
| `note`     | `string 或 null` | 备注                                                                 |

## 5 趋势 trend

### 5.1 GET `/api/trend/daily`

| 字段                         | 类型           | 含义                     |
| ---------------------------- | -------------- | ------------------------ |

| `series[].day`               | `int`          | 天序号（从 1）           |
| `series[].total_hydrocarbon` | `float`        | 当日总烃                 |
| `series[].rel_rate`          | `float 或 null` | 总烃月环比（%/月）＝(当日−`thc_base`)/`thc_base`×100% |

| `series[].is_pre`            | `bool`         | 是否涨势预警             |

| `thc_attention`              | `float`        | 注意线（10）             |
| `lookback_days`              | `int`          | 月环比回望天数（固定 30，今 vs 30 天前） |
| `pre_events`                 | `array`        | `is_pre===true` 的子集   |
| `summary.latest_rate`        | `float 或 null` | 末日月环比               |

## 6 判型 diagnose

日历色带共用 `GET /api/detect/series`。

### 6.1 GET `/api/diagnose/day/{day}`

单日判型。判型结果在嵌套对象 **`diagnosis`** 内。


| 字段        | 类型            | 含义                            |
| ----------- | --------------- | ------------------------------- |
| `date`      | `string`        | 监测日                          |
| `grade`     | `string`        | 综合最高档                      |
| `is_pre`    | `bool`          | 涨势预警                        |
| `gases`     | `object`        | `{ h2, ch4, c2h4, c2h6, c2h2 }` |
| `co`        | `float 或 null` | 一氧化碳（μL/L）               |
| `co2`       | `float 或 null` | 二氧化碳（μL/L）               |
| `diagnosis` | `object`        | 见下                            |

**diagnosis**：


| 字段                | 类型             | 含义                                           |
| ------------------- | ---------------- | ---------------------------------------------- |
| `triggered`         | `bool`           | 是否进入判型（注意值2+ **或** 速率超/涨势预警） |
| `grade`             | `string`         | 当日档位（与顶层一致）                         |
| `trigger_by`        | `string 或 null` | `grade` / `rate`；未触发为 null                |
| `trigger_note`      | `string 或 null` | 触发说明                                       |
| `is_pre`            | `bool`           | 是否涨势预警                                   |
| `rate_rising`       | `bool`           | 总烃月环比是否超注意                           |
| `reason`            | `string 或 null` | 未触发时的原因说明；已触发为 null              |
| `ratios`            | `object 或 null` | 三比值法结果，字段见下                         |
| `duval`             | `object 或 null` | 大卫三角法结果，字段见下                       |
| `key_gas`           | `object 或 null` | 特征气体法结果，字段见下                       |
| `fusion`            | `object 或 null` | 交叉研判结论，字段见下                         |
| `low_concentration` | `bool`           | §10.2.4 c 低浓度标志                          |

未触发时 `ratios` / `duval` / `key_gas` / `fusion` 均为 `null`。

**diagnosis.ratios（三比值 · 722 表6/表7）**：


| 字段         | 类型             | 含义                                                              |
| ------------ | ---------------- | ----------------------------------------------------------------- |
| `method`     | `string`         | 固定「三比值法」                                                  |
| `fault`      | `string`         | 表7 故障类型文案；无效时为「无对应编码」等                        |
| `code`       | `array 或 null`  | 三比值编码 `[C₂H₂/C₂H₄, CH₄/H₂, C₂H₄/C₂H₆]`，各为 0/1/2 |
| `ratios`      | `object`         | `{ C2H2/C2H4, CH4/H2, C2H4/C2H6 }`                                |
| `duval_code` | `string 或 null` | 映射到大卫三角分区代码（PD/D1/D2/T1/T2/T3/DT），供与三角对照       |
| `ok`         | `bool`           | 是否给出有效判型                                                  |
| `reason`     | `string 或 null` | 无效原因                                                          |

**diagnosis.duval（大卫三角 · 722 附录 C）**：


| 字段       | 类型             | 含义                                                |
| ---------- | ---------------- | --------------------------------------------------- |
| `method`   | `string`         | 固定「大卫三角形法」                                |
| `zone`     | `string 或 null` | 落区分区代码：PD / D1 / D2 / T1 / T2 / T3 / DT     |
| `fault`    | `string`         | 分区中文标签                                        |
| `percents` | `object`         | `{ pct_ch4, pct_c2h4, pct_c2h2 }`                   |
| `ok`       | `bool`           | 坐标是否可算                                        |
| `reason`   | `string 或 null` | 数据不足等原因                                      |

**diagnosis.key_gas（特征气体 · 722 表5）**：


| 字段        | 类型             | 含义                                           |
| ----------- | ---------------- | ---------------------------------------------- |
| `method`    | `string`         | 固定「特征气体法」                             |
| `fault`     | `string`         | 表5 六行之一（如油过热、油中电弧）             |
| `nature`    | `string 或 null` | `thermal` / `discharge`                        |
| `elevated`  | `array`          | 判定为偏高的气体名列表                         |
| `scores`    | `object`         | 各故障行工程得分                               |
| `ok`        | `bool`           | 是否给出有效判型                               |
| `primary`   | `array 或 null`  | 本次采用行的**主要特征气体**（气体键名，如 `["ch4","c2h4"]`），供前端高亮 |
| `secondary` | `array 或 null`  | 本次采用行的**次要特征气体**                   |
| `rows`      | `array 或 null`  | 表5 六行逐行明细，每项 `{fault, nature, primary, secondary, matched, chosen, reject}`：`matched`=是否命中、`chosen`=是否最终采用、`reject`=落选原因（供「为什么不是它」对照） |
| `note`      | `string 或 null` | 命中的表5 注1～5 说明                          |
| `reason`    | `string 或 null` | 无效原因                                       |
| `impl_note` | `string 或 null` | 偏高门槛与得分为工程实现，非表5数值            |

**diagnosis.fusion（交叉研判）**：


| 字段                     | 类型             | 含义                                              |
| ------------------------ | ---------------- | ------------------------------------------------- |
| `primary`                | `string`         | 主结论（故障类型文案）                            |
| `primary_code`           | `string 或 null` | 主结论分区代码                                    |
| `nature`                 | `string 或 null` | 性质枚举：`thermal` / `discharge` 等              |
| `nature_label`           | `string`         | 性质中文（过热 / 放电等）                         |
| `confidence`             | `string`         | 可信度：高 / 中 / 低                              |
| `confidence_reason`      | `string`         | 可信度依据说明                                    |
| `ratio_duval_consistent` | `bool 或 null`   | 三比值与大卫三角是否落格一致                      |
| `nature_agree`           | `bool 或 null`   | 三方法性质是否同向                                |
| `stance`                 | `string`         | 研判姿态                                          |
| `provisional`            | `bool`           | 是否暂定（试验仅核实）                            |
| `reasoning`              | `array`          | 推理条目 `[{ label, text, cite }]`                |
| `summary`                | `string`         | 一句话结论                                        |
| `measures`               | `array`          | 建议试验名列表                                    |
| `measures_appendix_d`    | `array`          | 附录 D 试验映射                                   |
| `measures_1685`          | `array`          | 1685 试验文案列表                                 |
| `measures_1685_items`    | `array`          | 1685 试验结构化项 `[{ clause, test, why }]`       |
| `measures_basis`         | `array`          | 试验建议依据                                      |
| `measures_purpose`       | `string`         | `recommend`（建议）/ `verify`（核实）             |
| `paper_note`             | `string 或 null` | 涉纸等辅助说明（如有）                            |
| `aux_ratios`             | `object`         | 辅助比值：`co2_co` / `c2h2_h2` / `o2_n2` / `notes` |

## 10 分析助手 assistant

分析助手挂载于 Agent 页抽屉，**判定仍走 `/api/agent/run` 同一内核**；本组接口管意图调度、规则解释与会话状态。

### 10.1 POST `/api/assistant/chat`

**请求体**：


| 字段              | 类型     | 必填 | 含义                                      |
| ----------------- | -------- | ---- | ----------------------------------------- |
| `message`         | `string` | 是   | 用户输入                                  |
| `session_id`      | `string` | 否   | 会话 id，首次可空                         |
| `selected_date`   | `string` | 否   | Agent 页当前选中日（解析「当前日期」兜底） |
| `force_template`  | `bool`   | 否   | 强制 Agent **报告**走规则模板（不影响助手解释润色） |

**返回 `data` 主要字段**：


| 字段           | 类型            | 含义                                           |
| -------------- | --------------- | ---------------------------------------------- |
| `session_id`   | `string`        | 会话 id                                        |
| `intent`       | `string`        | 识别意图（如 `run_analysis` / `explain_grade`） |
| `reply`        | `string`        | 助手文本回复                                   |
| `result`       | `object 或 null` | 若本次触发完整分析，则为 `run_agent()` 同构结果 |
| `selected_day` | `string 或 null` | 本次解析/切换的监测日                          |
| `suggestions`  | `array`         | 推荐追问（≤4 条）                              |
| `cite_ids`     | `array`         | 角标 id 列表                                   |
| `mode`         | `string`        | `rule` / `faq` / `llm`（解释润色成功时为 llm） |

### 10.2 POST `/api/assistant/sync`

主区按钮跑完分析后，将结果写入助手会话，便于直接追问解释。

**请求体**：`session_id`（可选）、`day`（必填）、`result`（必填，`run_agent()` 完整对象）。

**返回 `data`**：`session_id`、`selected_day`、`suggestions`、`reply`（回写会话的概览回复，含 LLM 润色或规则成稿）、`cite_ids`、`mode`（`rule` / `llm`）。

### 10.3 GET `/api/assistant/suggestions`

无参数。返回 `data.questions`（推荐追问列表）；无会话上下文时为默认推荐列表；有上下文时由前端在 `chat` / `sync` 响应中携带动态列表。

## 11 全局错误码（信封 `code`）


| code | 含义                             |
| ---- | -------------------------------- |
| 200  | 成功                             |
| 400  | 业务失败（如无监测数据、缺参数） |
| 404  | 资源不存在（如日期不在范围内）   |
| 500  | 未捕获的服务端错误（框架层）     |

无数据时常见 `message`：`无监测数据,请先跑 synthesize_data + import_data`。
