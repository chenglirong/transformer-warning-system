**性质大类准确率:15/17 = 88.2%**。两例未命中(E-006、E-016)详解如下:

- **E-006**:原文铁芯短路(过热)伴轻微放电痕迹,判为**放电兼过热**;系统判**过热**。原因:末样乙炔仅 0.37μL/L(放电特征气极低)、甲烷 126/乙烯 132μL/L 高,气体只反映过热支,轻微放电未起量。
- **E-016**:原文匝间短路烧蚀(过热)+ 多次短路冲击致放电,判为**放电兼过热**;系统末样判**放电**。原因:末样乙炔已升到 5.6μL/L,气体只反映放电支;但前 4 点乙炔≈0、系统持续判过热(见 §5.2),过热支早已被捕捉到。

混合故障两支产气随时间此消彼长,任何**单点** DGA 只能落到当时更强的一支;系统逐点判型能把两支先后显影(见 §5.2),这正是连续判型相对单点研判的价值。

### 5.3  分级 + 趋势/紧急度


| 原文 D.1.2 说法                     | 系统在这条数据上的输出                         | 对齐        |
| ----------------------------------- | ---------------------------------------------- | ----------- |
| 总烃均超注意值 150μL/L             | 异常日总烃 287~425μL/L,全部落注意值2          | ✓          |
| H₂ 超注意值 150μL/L               | H₂ 145~189,进注意值2判据                      | ✓          |
| 本体评价「异常状态」                | 不做评分,对应分级=注意值2(非正常,需处置)       | ✓ 语义对齐 |
| 总烃趋于稳定 + 最大产气速率 6.7%/月 | 紧急度=中(暂稳:超含量注意值但月环比未超10%/月) | ✓ 语义一致 |

- 基线日(2005-03-11)=正常 ✓;
- 2005-05-19 起各日≥注意值2 ✓,
- 对应原文本体「异常状态」。
- 本案例采样为月/季间隔,系统 §9.3.2「今 vs 30 天前」月环比窗口取不到点算不出,故趋势直接以原文「6.7%/月」
- 核算:未超 10%/月 → 暂稳 → 紧急度「中」,与系统逐日判「中」一致。

## 6. 结论

- 附录E 故障性质大类准确率 **88.2%(15/17)**,2 例未命中均为混合故障的 DGA 单点局限,逐点演化已还原混合过程。
- 附录D 分级、趋势/紧急度与原文状态评价口径**全部一致**。
- 两组数据均来自国标原文真实色谱,验证结果**通过**。
