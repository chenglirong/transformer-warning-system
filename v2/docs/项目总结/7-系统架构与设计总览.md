# 系统架构与设计总览

## 一句话定位

把三部行业标准串成一条自动分析链:**检测分级**(DL/T 1498.2 表A.3 四档)+ **产气趋势/涨势预警**(DL/T 722 §9.3.2 相对产气速率)+ **故障类型判断**(722 三比值 / 大卫三角 / 特征气体多方法交叉研判)+ **措施建议**(722 附录D + 1685 附录B 试验映射)+ **附录 G 分析报告**。创新点 = **智能体(Agent)编排**整条流程。

## 技术栈


| 层       | 技术                                                                                 | 说明                                                  |
| -------- | ------------------------------------------------------------------------------------ | ----------------------------------------------------- |
| 后端     | Python 3.11 + FastAPI + SQLAlchemy 2.0 + pandas + numpy                              | 算法层输入输出 DataFrame,与 Web/DB 解耦               |
| 报告导出 | reportlab                                                                            | PDF 二进制流导出,版式对齐 ReportCardG.vue             |
| 数据库   | SQLite(`v2/data/app.db`，表 `monitoring` + `transformers`)                           | 时序 + 铭牌台账;DB 路径走`config.py` 绝对路径         |
| 前端     | Vue 3(`<script setup>`) + Vue Router + Element Plus + ECharts + axios + iconify-icon | 后台管理布局:左侧栏 + 顶栏 + 内容区                   |
| LLM      | 通义千问 qwen-max（阿里云北京 MaaS，可选）                                           | Agent 报告写「人话」；助手**解释类**回复润色（失败回规则原文）。不改档位/判型 |

## 目录结构

```
v2/
├── BE/                     后端 FastAPI
│   ├── app/
│   │   ├── main.py         入口:挂业务路由 + CORS
│   │   ├── config.py       DB 绝对路径、CORS、.env 加载
│   │   ├── core/response.py 统一响应信封 {status,code,message,data}
│   │   ├── db/             session(引擎/Session 工厂) + models(ORM)
│   │   ├── api/            dataset / detect / trend / diagnose / warning / decision / agent / assistant 路由
│   │   └── algorithms/     纯算法
│   │       ├── synthesis.py       合成 360 天时序
│   │       ├── detect/            表A.3 四档 + 紧急度
│   │       ├── diagnose/          三比值 / Duval / 特征气体 / 交叉研判 / 试验
│   │       ├── agent/             工作流编排 + 决策 + run_logs 展开日志 + 报告 + 表G + 导出
│   │       ├── assistant/         分析助手：意图 / 规则解释 / FAQ / 会话 sync（不改七步内核）
│   │       └── knowledge/refs.py  判据条目库(角标依据)
│   └── scripts/            init_db / synthesize_data / import_data / seed_transformer / run_std_cases（国标案例对账）
└── FE/src/
    ├── router/index.js     8 页路由(数据集/检测/趋势/告警/决策/判型/Agent/知识库)；`/assistant` 重定向 Agent 并开抽屉
    ├── layout/AppLayout.vue 左侧栏后台壳(三组导航)
    ├── service/
    │   ├── http.js         axios 封装 + 响应拦截
    │   ├── checkStatus.js  HTTP 状态码错误提示
    │   └── assistantApi.js 分析助手 chat / sync / suggestions
    ├── views/              8 个页面
    ├── components/         ReportCardG / StdCite / AssistantPanel / TablePager
    ├── utils/
    │   └── reportDownload.js PDF 报告下载(前端触发后端二进制流)
    ├── assets/
    │   ├── styles/         全局 token / 组件 / 壳 / overview CSS
    │   └── standards/      国标条文截图
    └── data/stdRefs.js     国标条目文案 + 原图索引
```
