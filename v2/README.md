# 设备状态分析智能体

## 系统一句话

面向 220kV 及以下油浸式变压器,基于 DGA 的**分析智能体后台软件**:检测(分级) + 故障类型判断 + 分级告警 + 产气趋势/涨势预警 + 监测决策 + 报告导出;创新点 = **智能体(Agent)编排** 整个分析流程。

- **题目**:《变压器油中溶解气体分析智能体研究与实现》
- **数据**:全程跑合成 360 天时序(原始 743 快照仅作合成分布原料);**7 气全生成**(表A.3 落档只用乙炔/H₂/总烃;CO/CO₂ 走表5/CO₂/CO)
- **输出定位**:依 DL/T 722 / 1498.2 / 1685 输出档位、故障类型、措施建议(附录D / 1685 附录B 试验映射)、附录 G 档案卡片(可导出 PDF);**不做健康评分**、**不给运维处置指令**(只到试验层),成因/部位定位归展望

## Agent 七步顺序

当日气体 → **分级检测** → **产气趋势** → 处置紧急度 → **故障判型** → 监测决策 → 生成报告

- **判型触发**:注意值2/告警 **或** 总烃月环比超注意(含涨势预警);处置紧急度仍仅注意值2+
- **用词**:步骤名「分级检测 / 产气趋势 / 故障判型」;结果态「涨势预警」(档未达注意值2) / 「涨势快」 / 「未超注意值」;UI 统称「检测周期」(角标区分 A.3.1 / §5.5.5)
- **运行日志**:后端 `run_logs.build_log_lines` 展开为 `log_lines`,前端流式渲染;`steps[].log` 仍为一句摘要
- **LLM**:报告意见与 G.2 试验成稿人话；助手解释类回复可选润色；均不改判定；无密钥或失败 → 规则模板/原文
- **分析助手**:Agent 页抽屉；触发分析走同一 `run_agent()`；主区↔助手双向 sync
- **报告导出**:PDF — 后端 reportlab 生成,前端触发下载

## 关键约束

- **算法层与 Web/DB 解耦**:`algorithms/` 不碰 HTTP/DB
- **数值以国标原图为准**
- **两套速率各归各**(D-004):表A.3 %/周只落档;722 §9.3.2 %/月管紧急度 / 趋势 / 涨势预警
- **绝对产气率(mL/天)**:式1 需油重与油密度;演示台账有油重仍缺密度 → 报告该格填「—」,相对速率写在分析意见
- **不做**:时序预测、健康评分、运维处置指令、成因/部位定位、自由 ReAct

```bash
# 可选: cp .env.example .env 并填 LLM_API_KEY
uvicorn app.main:app --reload --port 8000

# 前端
cd v2/FE && npm run dev
```
